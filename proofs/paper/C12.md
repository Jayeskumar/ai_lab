# Cycle C12 — Written proofs (relational one-heap games)

**Setting.** A one-heap game is given by an option relation: from n a move goes to
a smaller position. Its Grundy function g is the unique function with
g(n) = mex{ g(m) : m an option of n } (unique because options are smaller;
Lean: `IsGrundy.unique`). For splitting games a move replaces a heap n by two
heaps a + b = n and the option value is g(a) XOR g(b). A position is a
P-position (the player to move loses) iff g(n) = 0 (Lean: `IsGrundy.zero_pset`).
All proofs below are by strong induction on n using this characterisation: to
show g = f it suffices that, for every n, f(n) is not the f-value of any option
of n while every smaller value is.

v₂(n) is the 2-adic valuation, Ω(n) the number of prime factors with
multiplicity, popcount(n) the number of 1-bits. The *odd part* of n ≥ 1 is
n / 2^v₂(n).

## Theorem 1 (CLM-C12-01) — divisibility games

(a) G01 "subtract a divisor d | n with d < n": g(n) = v₂(n) (n ≥ 1).
(b) G02 "subtract any divisor (d = n allowed)": g(n) = v₂(n) + 1 (n ≥ 1).
(c) G04 "move to a proper divisor": g(n) = Ω(n).

*Proof.* (a) Let k = v₂(n). For j < k, d = 2^j divides n, d < n, and
v₂(n − 2^j) = j because v₂(n) > j; so every value < k occurs. No option has value
k: if d | n, d < n, then v₂(d) ≤ k; if v₂(d) < k then v₂(n − d) = v₂(d) < k; if
v₂(d) = k then n = 2^k a, d = 2^k b with a > b both odd, so
v₂(n − d) = k + v₂(a − b) ≥ k + 1. (b) The options are those of (a) together
with 0 (value 0); by induction the values of the (a)-options are v₂(n−d) + 1,
which cover 1, …, k and miss k + 1, so mex = k + 1. (c) Proper divisors of n
have Ω-values covering 0, …, Ω(n) − 1 (along a chain of divisors) and never
Ω(n). ∎

*Literature.* (b) and (c) are Theorems 2 ("saliquot") and 1 ("maliquot") of
Iannucci & Larsson, "Game values of arithmetic functions" (arXiv:2101.07608,
2021). The win/loss version of (a) is the well-known "Divisor Game" programming
puzzle (LeetCode 1025: the first player wins iff n is even); its Grundy function
follows from the saliquot proof. OEIS A007814, A001511, A001222.

## Theorem 2 (CLM-C12-02) — coprimality games

(a) G05 "move to m with 1 ≤ m < n and gcd(m, n) = 1": g(1) = 0 and g(n) = j for
n ≥ 2, where the smallest prime factor of n is the j-th prime. G07 "subtract k
with 1 ≤ k < n and gcd(k, n) = 1" is the same game, since gcd(n − m, n) = gcd(m, n).
(b) G06 "move to m with 1 ≤ m < n and gcd(m, n) > 1": g(2k) = k − 1 (k ≥ 1),
g(m) ≤ (m − 1)/2 for odd m, and the P-positions n ≥ 1 are exactly 1 and the
primes.

*Proof.* (a) Let n ≥ 2 have smallest prime p_j. For i < j the prime p_i < p_j ≤ n
does not divide n, so it is an option, with value i by induction; together with
m = 1 (value 0) all values < j occur. An option m ≥ 2 with value j would be
divisible by p_j, contradicting gcd(m, n) = 1.
(b) Simultaneous induction. Odd m: every option x < m has g(x) ≤ (x − 1)/2
(even x by the even formula, odd x by induction), so all option values are
≤ (m − 3)/2 and mex ≤ (m − 1)/2. Even n = 2k: all even m with 2 ≤ m < n are
options, with values m/2 − 1 covering 0, …, k − 2; an odd option shares an odd
prime q with n, so it is ≤ n − q ≤ 2k − 3 and has value ≤ k − 2. Hence
g(2k) = k − 1. Zeros: primes and 1 have no options; an odd composite m has its
smallest prime p < m as an option (value 0); g(2k) = 0 only for k = 1. ∎

*Literature.* (a) is Theorem 5 ("totative") of Iannucci & Larsson, who also note
the subtraction equivalence. (b) is their "nontotative" game: their Theorem 6
gives SG(2n) = n and SG(n) = 1 iff n is prime, i.e. exactly our values plus one
for n ≥ 2 (their game also allows the move to the residue 0); they also prove
SG(n) ≤ n/2 and SG(n) = ⌊(n+1)/4⌋ for n ≡ 3 (mod 6). The sequence is OEIS
A279119 ("lexicographically earliest sequence such that a(i) = a(j) implies
gcd(i, j) = 1" is exactly this mex recursion); the zero set is A008578.

## Theorem 3 (CLM-C12-03) — P-positions of the deleting-divisors game

For G03 "subtract a divisor d with 1 < d < n", the P-positions are exactly 0, the
odd numbers, and the powers 2^(2j+1).

*Proof.* Machine-checked: `Infinity.C12.g03_pset` and
`Infinity.C12.g03_P_positions` (`proofs/lean/Infinity/C12_Games.lean`). Idea: an
odd n has only odd non-trivial divisors d, and n − d is even, nonzero, and
divisible by the odd d ≥ 3, hence not a power of 2 — so no option is a
P-position. An even n with odd part m > 1 can move to the odd number
n − m = m(2^a − 1). Powers of 2: the options of 2^a are 2^i(2^(a−i) − 1); the only
one that is a power of 2 is 2^(a−1), so 2^a is a P-position iff 2^(a−1) is not;
with 2 terminal this gives exactly the odd exponents. ∎

*Literature.* This is Codeforces problem 1537D "Deleting Divisors" (Codeforces
Round #726, June 2021): the official solution declares the second player the
winner exactly for odd n and for n = 2^k with k odd. **Rediscovery.** The
Grundy values are a different matter (Theorem 8).

## Theorem 4 (CLM-C12-05) — bitwise and quotient games

(a) G13 "move to a proper binary submask": g(n) = popcount(n).
(b) G19 "move to n mod k, 1 ≤ k < n": g(n) = ⌊log₂((n + 1)/3)⌋ + 1 for n ≥ 2.
(c) G20 "move to ⌊n/k⌋, 2 ≤ k ≤ n": g(n) = ⌊log₂ n⌋ for n ≥ 1.

*Proof.* (a) Proper submasks have popcounts covering 0, …, popcount(n) − 1 and
never popcount(n). (b) The options of n are exactly the r with 0 ≤ r < n/2:
k = 1 gives 0, k = n − r gives r for 1 ≤ r < n/2, and n mod k < k ≤ n/2 for
k ≤ n/2 while n mod k = n − k < n/2 for n/2 < k < n. So
g(n) = mex g([0, ⌈n/2⌉)). By induction g is nondecreasing with steps of at most
1 and g(n) = g(⌈n/2⌉ − 1) + 1 for n ≥ 2, so the first n with g(n) = v is f(v) with
f(1) = 2, f(v + 1) = 2f(v) + 1, i.e. f(v) = 3·2^(v−1) − 1; hence
g(n) = max{v : 3·2^(v−1) − 1 ≤ n}.
(c) ⌊n/2^j⌋ (1 ≤ j ≤ ⌊log₂ n⌋) are options with values ⌊log₂ n⌋ − j; every option
is ≤ n/2 and has value ≤ ⌊log₂ n⌋ − 1. ∎

*Literature.* (b) is Theorem 12 ("residue-throw-divisor") of Iannucci & Larsson,
stated there with the proof "left to the reader"; the proof above supplies it.
The sequences are OEIS A000120, A099396 (shifted: g(n) = A099396(n + 1)) and
A000523. (a) is Nim on the number of 1-bits; (c) is elementary.

## Theorem 5 (CLM-C12-06) — the residue lemma and powers of k

*Residue lemma (Lean: `residue_grundy`).* If no element of the move set S is
divisible by q and 1, …, q − 1 ∈ S, the subtraction game S has g(n) = n mod q.
*Corollary (Lean: `power_of_two_grundy`).* Subtract-a-power-of-2: g(n) = n mod 3.

*Powers of k (written proof).* For every k ≥ 2, subtract-a-power-of-k has the
same Grundy function as the finite subtraction game {1, k}: for k odd
g(n) = n mod 2; for k even g(n) = P(n mod (k+1)) with P(r) = r mod 2 for r < k and
P(k) = 2.

*Proof.* k^i ≡ (−1)^i (mod k+1), so every move is ≡ 1 or ≡ k ≡ −1 (mod k+1).
For k odd every power is odd and 1 ∈ S: the residue lemma with q = 2 applies.
For k even put f(n) = P(n mod (k+1)) and let r = n mod (k+1). Every option of n
has residue r − 1 or r + 1 (mod k+1); the option n − 1 exists for n ≥ 1 and the
option n − k (residue r + 1) exists for n ≥ k. Check the mex equations:
* r = 0: n = 0 has no option (f = 0); for n ≥ k + 1 the option values are
  P(k) = 2 and P(1) = 1, mex 0 ✓.
* r odd (1 ≤ r ≤ k − 1): the values are P(r − 1) = 0 and possibly
  P(r + 1) ∈ {0, 2}, mex 1 ✓.
* r even, 2 ≤ r ≤ k − 2: the values are P(r − 1) = 1 and possibly P(r + 1) = 1,
  mex 0 ✓.
* r = k (so n ≥ k and both options exist): the values are P(k − 1) = 1 and
  P(0) = 0, mex 2 ✓.
The same computation applies verbatim to the finite game {1, k}. ∎
(Verified for k = 2..20, n ≤ 2·10⁴, EXP-C12-02.)

## Theorem 6 (CLM-C12-07) — splitting games

In any take-and-break game in which a heap is replaced by two nonempty heaps
from a set of allowed splits, and every heap n ≥ 2 has at least one allowed
split, g(n) = 1 for even n and g(n) = 0 for odd n (n ≥ 1). Machine-checked:
`Infinity.C12.split_parity`. (An even n splits into two parts of equal parity,
whose values are equal and XOR to 0; an odd n into parts of opposite parity,
XOR 1.) Equivalently, every play lasts exactly n − 1 moves. Covers G16 (coprime
parts) and G17 (a | b).

## Theorem 7 (CLM-C12-08) — sparse sets with density-zero P-positions

For subtract-a-square and subtract-a-triangular-number, the set of P-positions
is infinite and has natural density 0. Consequently neither Grundy sequence is
eventually periodic or eventually arithmetic-periodic.

*Proof.* Two P-positions cannot differ by a move (the larger could move to the
smaller). So the P-set of subtract-a-square contains no two elements differing by
a nonzero square, and by the Furstenberg–Sárközy theorem (Furstenberg 1977,
Sárközy 1978) it has density 0. For triangular numbers, the P-set contains no
two elements differing by T_{2m} = m(2m + 1) = Q(m) with Q ∈ ℤ[m], Q(0) = 0, so it
has density 0 by the polynomial version of Sárközy's theorem (Kamae and
Mendès France 1978; also Bergelson–Leibman). The P-set is infinite: if p were
its largest element, every n > p would be an N-position and so would lie in
P + S, a finite union of translates of the move set S; but S has density 0 and
cannot cover a whole tail of ℕ. An infinite eventually periodic set has positive
density; an eventually arithmetic-periodic sequence (g(n + p) = g(n) + s, s ≠ 0)
has only finitely many zeros. ∎

*Literature.* For subtract-a-square the argument is known: the cold positions
form a maximal square-difference-free set, so the Furstenberg–Sárközy theorem
gives density zero (see the Wikipedia article "Square-difference-free set" and
D. Eppstein, "Faster evaluation of subtraction games", FUN 2018). The triangular
case is the same argument with an intersective polynomial.

## Theorem 8 (CLM-C12-04) — Grundy values of the deleting-divisors game

Let g be the Grundy function of G03 ("subtract a divisor d with 1 < d < n") and
write n = 2^a m with m odd. Then g(n) = 0 for odd n, and for a ≥ 1:

| odd part m | g(2^a m) |
|---|---|
| m ≥ 17 | a |
| 1 | 0 for a odd; a − 1 for a even, except g(16) = 2 |
| 3 | 2, 3, 4, 3, 6 for a = 1..5; a − 2 for a ≥ 6 |
| 5 | 1, 3, 4, 3, 6 for a = 1..5; a + 2 for a ≥ 6 |
| 7, 9, 11, 15 | a for a ≤ 2; a + 1 for a ≥ 3 |
| 13 | a for a ≤ 3; a + 1 for a ≥ 4 |

In particular |g(n) − v₂(n)| ≤ 2 for every n that is not an odd power of 2, and
the record values (g(n) > g(n') for all n' < n) occur at n = 5·2^a for a ≥ 6.

Call F the function defined by the table. *Stable values:* for odd part
m' ≤ 15 and exponent b ≥ 6, F(2^b m') equals 0 or b − 1 (m' = 1, b odd or even),
b − 2 (m' = 3), b + 2 (m' = 5) or b + 1 (m' = 7, …, 15).

*Proof (computer-assisted).* We show g = F by strong induction on n.

*Step 0 (n ≤ 10⁵).* g(n) = F(n) by exact computation (EXP-C12-06, 0 mismatches).

*Step 1 (n odd).* The zero set of F is {0} ∪ odd numbers ∪ {2^(2j+1)}, which is
the P-set of G03 (Theorem 3, Lean `g03_pset`); hence no option of an odd n has
F-value 0, and F(n) = 0 = mex.

*Step 2 (n = 2^a m > 10⁵, a ≥ 1, m ≥ 17).* F(n) = a. Every option is
x = n − 2^i e with e | m and 1 < 2^i e < n.
(i) All values below a occur: x = n − 2^j (1 ≤ j < a) has v₂(x) = j and odd part
2^(a−j) m − 1 ≥ 17, so F(x) = j; x = n − m is odd, F(x) = 0.
(ii) The value a does not occur. If i < a, then x = 2^i (2^(a−i) m − e) with odd
cofactor ≥ m ≥ 17, so F(x) = i < a. If i = a (so e < m), write m − e = 2^k m'
with k ≥ 1 and m' odd; then x = 2^(a+k) m', and e | m' because the odd number e
divides m − e = 2^k m'. If m' ≥ 17 then F(x) = a + k ≠ a. If m' ≤ 15, then
n = 2^a e + x < 2x, so x > 5·10⁴ forces b = a + k ≥ 6 (as 2^5·15 = 480), and F(x)
is a stable value.
It equals a only if (m' = 1, k = 1), giving e = 1 and m = 3, or (m' = 3,
k = 2), giving m = e + 12 ∈ {13, 15} — both contradict m ≥ 17. So mex = a.

*Step 3 (n = 2^a m > 10⁵, m ≤ 15).* Then a ≥ 13. Let i = a − t. Options with
t ≥ 5 have odd part 2^t m − e ≥ 31 and F-value i; for 1 ≤ i ≤ a − 5 they include
n − 2^i, and value 0 occurs among them iff m > 1. Options with 1 ≤ t ≤ 4 have
valuation i ≥ 9 and odd part o = 2^t m − e, so their F-value is a − t + c(o),
where c(o) = 0 for o ≥ 17 and is the stable offset for o ≤ 15 (for o = 1 the
value is 0 or i − 1 according to the parity of i). Options with i = a are
2^(a+k) m' with a + k ≥ 14, again stable, with value a + k + c(m') (0 or
a + k − 1 when m' = 1, according to the parity of a + k). The pairs (t, e) and
(k, m') do not depend on a. Hence the set of option values is
{1, …, a − 5} ∪ Z ∪ (a + D), where Z ⊆ {0} and the finite offset set D depend only
on m and the parity of a. The mex is therefore 0 or a + δ(m, a mod 2), and F(n)
has the same form, so it suffices to check one exponent of each parity. EXP-C12-06
checks the mex equation for F exactly for all m ≤ 15 and 13 ≤ a ≤ 100 (0
failures); the recorded offset sets at a = 13 and a = 14 confirm the shapes. ∎

*Checks.* EXP-C12-06 also verifies the mex equation for F at 3000 random even n
(odd parts 17 ≤ m < 10⁶, a ≤ 40) and 1000 random odd n < 10⁸ (0 failures), and
finds 96 positions n ≤ 10⁵ with g(n) ≠ v₂(n), all with odd part ≤ 15.

*Trust base.* Exact Python integer arithmetic (Steps 0 and 3), the Lean P-set
theorem (Step 1) and the written Steps 2 and 3 (not yet reviewed by the Skeptic).

*Literature.* Codeforces 1537D determines only the P-positions; the Grundy
sequence is not in the OEIS (EXP-C12-04), the game does not appear among the
divisor games of Iannucci & Larsson, and web searches found no Grundy analysis.
**Potentially novel** (not a priority claim). Compare G01 (the same game with
d = 1 allowed), where g = v₂ exactly: forbidding the move "subtract 1" perturbs
the Grundy function only on numbers with odd part ≤ 15 and on the odd powers of
2.
