# Cycle C10 — Written proofs (the cost of counting)

The *cost* of the increment n → n+1 in a representation is the number of digit
positions whose digit changes. Averages are over 0 ≤ n < N, N → ∞.

## Theorem 1 (CLM-C10-01) — classical constants

Average cost: base b → b/(b−1); negabinary → 2; balanced ternary → 3/2;
factorial base → e − 1; binary-reflected Gray code → 1 (exactly 1 at every
step).

*Proof.* In base b, digit k changes exactly when b^k divides n+1, i.e. with
frequency b^{−k}; summing, Σ_k b^{−k} = b/(b−1). For negabinary (base −2) and
balanced ternary, digit k is a periodic function of n with period b^{k+1}
(b = 2, 3) made of b constant blocks of length b^k with distinct consecutive
values, so again it changes with frequency b^{−k}. In the factorial base
digit k (radix k+1) changes when k! divides n+1: Σ_{k≥1} 1/k! = e − 1. Gray
code changes one bit per step by construction. ∎

## Theorem 2 (CLM-C10-02) — Zeckendorf counting

With G = 1, 2, 3, 5, … let T_m be the total cost of counting from 0 to G_m − 1.
Then T_{m+1} = T_m + T_{m−1} + ⌈m/2⌉ + 1, T_m = 2G_m − ⌈m/2⌉ − 2, and the
average cost of Zeckendorf counting tends to 2 (exactly as for binary).

*Proof.* The numbers below G_{m+1} split into [0, G_m) and
[G_m, G_m + G_{m−1}); the latter are "1 0" followed by an arbitrary
Zeckendorf string of length m − 1, so counting through them costs T_{m−1}.
The step G_m − 1 → G_m turns the alternating string 1010… (⌈m/2⌉ ones) into
10…0, costing ⌈m/2⌉ + 1. This gives the recurrence; the closed form holds for
m = 0, 1 and is preserved because ⌈(m+1)/2⌉ = ⌈(m−1)/2⌉ + 1. Hence
T_m/G_m → 2. For general N, decompose [0, N) along the Zeckendorf digits of N
into O(log N) blocks of the form [x, x + G_k); each costs T_k plus a transition
of O(log N), so the total is 2N + O(log² N). ∎

*Refutation (CLM-C10-03).* The guess that the sparser Zeckendorf system counts
more cheaply than binary (H-C10-0) is false: both average exactly 2.

## Theorem 3 (CLM-C10-04) — firings in exchange systems

For a terminating carry rule (m; b), B = Σ b_j < m, the average number of
firings per increment tends to 1/(m − B).

*Proof.* By the abelian property (C02 Theorem 1), performing the increments
one at a time fires every level exactly as often as stabilising n tokens at
once, i.e. (n − s(n))/(m − B) firings in total, where s(n) is the number of
tokens in rep(n). Stable configurations have at most m − 1 tokens per level
and rep(n) has O(log n) levels (B < m gives r > 1), so s(n) = O(log n). ∎

## Theorem 4 (CLM-C10-05) — single-offset rules

If b has a single nonzero entry b_g = q (so 1 ≤ q < m), then every increment
costs exactly (number of firings) + 1 digit changes, and the average cost is
1 + 1/(m − q). (For g = 1 this covers integer and rational bases.)

*Proof.* Induction along the cascade: level 0 receives one token and level
k + g receives q per firing at level k. If each level fires at most once, a
receiving level goes from c ≤ m − 1 to c + q ≤ 2m − 2 < 2m and fires at most
once — so each level fires at most once. A fired level changes by (received)
− m ∈ {1 − m, q − m} ≠ 0; the last receiving level does not fire and changes by
q ≠ 0 (or by 1 at level 0); no other level is touched. So the changed levels
are the fired ones plus one. Average via Theorem 3. ∎

## Observation 5 (CLM-C10-06) — multi-offset rules

When b has two or more nonzero entries, a level can receive several tokens in
one increment and the cost exceeds firings + 1 by a rule-dependent average
excess, measured at e.g. 0.500 (3[k] → [k+1]+[k+2]), 0.333 (4 → 1,1),
0.643 (3 → 0,1,1), 0.714 (3 → 1,0,1), 0.831 (4 → 1,1,1) (EXP-C10-03). We
conjecture these limits exist and are expectations under the invariant
(Parry-type) measure of the digit process; no formula is known to us.
