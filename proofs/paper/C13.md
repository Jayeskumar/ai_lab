Setting (as in `proofs/paper/C06.md`). An *anchored magma* of size N is a binary
operation ⋆ on ℤ/N with x ⋆ 0 = x + 1. A *law* is an identity s = t between
terms in variables; the *spectrum* Spec(E) of a set E of laws is the set of N
admitting an anchored model. The *affine* anchored tables are
x ⋆ y = x + a·y + 1 (a ∈ ℤ/N); Aff(E) ⊆ Spec(E) is the set of N for which some
affine table satisfies E.

*Affine evaluation.* In the affine table with parameter a every term t
evaluates to a linear form t = Σ_v C_t[v](a)·v + D_t(a) with C, D ∈ ℤ[a]:
C_v[v] = 1, D_v = 0, and for t = uw: C_t = C_u + a·C_w, D_t = D_u + a·D_w + 1
(because (Σ C_u v + D_u) ⋆ (Σ C_w v + D_w) = Σ C_u v + D_u + a(Σ C_w v + D_w) + 1).
Hence a law s = t holds in the table with parameter a (mod N) iff every
polynomial of its *affine system* Sys(s = t) = {C_s[v] − C_t[v]} ∪ {D_s − D_t}
vanishes at a modulo N. (A polynomial identity in the variables over ℤ/N: a
linear form vanishes for all values of the variables iff all its
coefficients vanish, since each variable can be 1 while the others are 0.)

## Theorem 1 (CLM-C13-01) — the structure of affine spectra

Let E be a finite set of laws and Sys(E) = ∪ Sys(e) ⊂ ℤ[a].

(a) An anchored table of the form x ⋆ y = αx + βy + γ (α, β, γ ∈ ℤ/N) has
α = γ = 1; so the affine anchored tables are exactly x + a·y + 1.
(b) Aff(E) = {N : the polynomials of Sys(E) have a common root modulo N}.
(c) Aff(E) is closed under divisors and under products of coprime elements;
hence N ∈ Aff(E) iff p^e ∈ Aff(E) for every prime power p^e ‖ N.
(d) If the polynomials of Sys(E) have no common factor of positive degree in
ℚ[a] (and Sys(E) ≠ ∅), then Aff(E) is finite and equals the set of divisors
of L = max Aff(E); L divides every non-zero integer of the ideal generated by
Sys(E) in ℤ[a] (for instance every non-zero resultant of two of them).
(e) If they have a common factor G of positive degree, Aff(E) is infinite.
If Sys(E) = ∅, Aff(E) = ℕ.
(f) *(Added after the Skeptic's review, reviews/skeptic_C13_C19.md C2.)* Let
G′ be the primitive integer polynomial proportional to the ℚ-gcd of Sys(E)
and h_f = f/G′ ∈ ℤ[a]. Then {N : G′ has a root mod N} ⊆ Aff(E). If R′ ≠ 0 is
an integer in the ideal generated by the h_f (it exists, since the h_f have no
common factor over ℚ) and p ∤ R′, then p^e ∈ Aff(E) iff G′ has a root mod
p^e, for every e ≥ 1.

*Proof.* (a) The anchor gives αx + γ = x + 1 for all x; x = 0 gives γ = 1 and
then x = 1 gives α = 1. (b) is the affine evaluation above. (c) If a is a
common root modulo N and d | N, then a mod d is a common root modulo d. If
gcd(N, M) = 1 and a, b are common roots modulo N and M, the Chinese remainder
theorem gives c ≡ a (mod N), c ≡ b (mod M), and each f ∈ Sys(E) satisfies
f(c) ≡ f(a) ≡ 0 (mod N) and ≡ f(b) ≡ 0 (mod M), so f(c) ≡ 0 (mod NM). The
prime-power description follows. (d) ℚ[a] is a principal ideal domain, so
polynomials without a common factor generate the unit ideal:
Σ u_f f = 1 with u_f ∈ ℚ[a]. Clearing denominators gives Σ u′_f f = R with
u′_f ∈ ℤ[a] and R ∈ ℤ∖{0}; when two of the polynomials are already coprime,
their resultant is such an R. A common root modulo N then gives R ≡ 0 (mod N),
so Aff(E) ⊆ Div(R) is finite. A finite set closed
under divisors and coprime products is the set of divisors of its maximum: for
each prime p let p^{e_p} be the largest power of p in the set; the product
L = Π p^{e_p} is in the set by (c), every element divides L, and every divisor
of L is in the set. (e) Let G′ ∈ ℤ[a] be the primitive integer polynomial proportional to G.
Since G′ divides every f ∈ Sys(E) in ℚ[a] and is primitive, Gauss's lemma
gives f = G′·h_f with h_f ∈ ℤ[a]. By Schur's theorem the non-constant integer
polynomial G′ has roots modulo infinitely many primes p, and every root of G′
modulo p is a common root of all f, so every such p lies in Aff(E). (f) A root
of G′ is a root of every f = G′h_f. Conversely, let a be a common root mod
p^e. If all h_f(a) ≡ 0 (mod p), then R′ = Σ u_f h_f (u_f ∈ ℤ[a]) gives p | R′,
a contradiction; so some h_f(a) is a unit mod p^e, and f(a) = G′(a)h_f(a) ≡ 0
forces G′(a) ≡ 0 (mod p^e). (Proof by the Skeptic, checked by the Director.) ∎

*Remark.* Aff(E) ⊆ Spec(E) always; the laws for which equality holds
("affinely rigid" laws) have arithmetic spectra described by (b)–(e).

## Theorem 2 (CLM-C13-02) — right-normed laws have only translation models

Let V(y, z) be any term in the variables y, z (not containing x). Every anchored
model of (x ⋆ y) ⋆ z = x ⋆ V(y, z) is a *translation table*
x ⋆ y = x + 1 + κ(y) with κ a permutation of ℤ/N, κ(0) = 0, and κ satisfies
κ(V(y, z)) = κ(y) + κ(z) + 1 for all y, z (V evaluated in the model).

*Proof.* Put z = 0: (x ⋆ y) + 1 = x ⋆ σ(y) with σ(y) := V(y, 0), a function of
y alone. By induction x ⋆ σ^k(0) = x ⋆ 0 + k = x + 1 + k for all k ≥ 0. For x = 0
the values 1 + k (0 ≤ k < N) are distinct, so the elements σ^k(0) (0 ≤ k < N)
are distinct and exhaust ℤ/N. Define κ(σ^k(0)) = k for 0 ≤ k < N; then
x ⋆ y = x + 1 + κ(y) for every y, κ is a bijection and κ(0) = 0. Substituting
the translation form, (x ⋆ y) ⋆ z = x + 2 + κ(y) + κ(z) and
x ⋆ V(y, z) = x + 1 + κ(V(y, z)). ∎ (Lean: `translation_form`, `right_normed_translation`.)

## Theorem 3 (CLM-C13-03) — the W-family: polynomial spectra a·P(a) ≡ 1

Let W(z) be a term in the single variable z, and for a binary tree let
c_W(a) = Σ_{leaves ℓ of W} a^{r(ℓ)}, where r(ℓ) is the number of right steps
on the path from the root to ℓ. The anchored models of size N of

  (x ⋆ y) ⋆ z = x ⋆ (y ⋆ W(z))

are exactly the affine tables x ⋆ y = x + 1 + a·y with a·c_W(a) ≡ 1 (mod N),
distinct roots giving distinct models. The polynomials P = c_W that occur are
exactly the polynomials with non-negative integer coefficients, P(0) = 1 and
no gaps (every coefficient up to the degree is ≥ 1).

*Proof.* (i) By Theorem 2 (V(y, z) = y ⋆ W(z)) every model is a translation
table x ⋆ y = x + 1 + κ(y) with
  κ(y + 1 + κ(W(z))) = κ(y) + κ(z) + 1.        (∗)
(ii) Put z = 0 and let w₀ be the value of the closed term W(0): (∗) gives
κ(y + c) = κ(y) + 1 with c = 1 + κ(w₀), hence κ(y + jc) = κ(y) + j for j ≥ 0.
If d = gcd(c, N) > 1 then j = N/d gives jc ≡ 0 and N/d ≡ 0 (mod N), impossible
for N ≥ 2; so c is a unit, κ(jc) = j, and κ(y) = a·y with a = c^{−1}. The model
is affine.
(iii) For affine tables, a one-variable term evaluates to W(z) = c_W z + d_W
with c_z = 1, d_z = 0, c_{uv} = c_u + a c_v, d_{uv} = d_u + a d_v + 1; the first
recursion gives c_W = Σ_ℓ a^{r(ℓ)}. By induction c_W = a·d_W + 1 (true for z;
if c_u = a d_u + 1 and c_v = a d_v + 1 then
c_u + a c_v = a(d_u + a d_v + 1) + 1). The affine system of the law is
{a²c_W − a, a²d_W + a − 1} = {a·(a c_W − 1), a c_W − 1}, so the law holds iff
a·c_W(a) ≡ 1. Distinct a give distinct tables (0 ⋆ 1 = 1 + a).
(iv) Realisable P. Unrolling the left spine of W, c_W = 1 + a·Σ_j c_{V_j} over
the right children V_j of the left spine. Every realisable P therefore has
P(0) = 1 and, if deg P ≥ 1, the coefficient of a equals the number of right
children (≥ 1), and inductively no gaps. Conversely, if P is gap-free with
P(0) = 1, write Q = (P − 1)/a, k = Q(0) = p₁ ≥ 1 and Q = (Q − (k − 1)) + (k − 1)·1;
Q − (k − 1) is gap-free with constant term 1 and smaller degree than P, so it
is realised by some tree V by induction, and P is realised by the left spine
with right children V, z, …, z (k − 1 copies of z). ∎ (Lean, parts (i)–(iii): `w_family_models` and its converse
`w_family_model_of_root`, for every one-variable term given as an element of the inductive type `T1`.)

*Corollary 3a (n-bonacci laws).* For the right comb W = z(z(⋯(zz))) with n
leaves, P = 1 + a + ⋯ + a^{n−1}; with t = a^{−1} the condition is
t^n = t^{n−1} + ⋯ + t + 1. So the anchored spectrum of
(xy)z = x(y(z(z(⋯ z)))) is the set of N modulo which the n-bonacci polynomial
has a root (golden law for n = 2, tribonacci for n = 3), and the number of
models is the number of roots.

*Corollary 3b (quadratic laws).* For the left comb W = ((zz)z)⋯z with k + 1
leaves, P = 1 + k·a and the condition is k a² + a − 1 ≡ 0, of discriminant
1 + 4k.

## Theorem 4 (CLM-C13-04) — two of the finite spectra of CLM-C06-10

(a) The law x ⋆ (y ⋆ z) = ((z ⋆ x) ⋆ x) ⋆ y has anchored models exactly for
N ∈ {1, 3}; for N = 3 the model is unique, x ⋆ y = x + 1 + 2y.
(b) The law x ⋆ (y ⋆ z) = ((x ⋆ y) ⋆ z) ⋆ x has anchored models exactly for
N ∈ {1, 2}; for N = 2 the model is unique, x ⋆ y = x + 1.

*Proof of (a).* Write T(u, v) = u ⋆ v and r(u) = 0 ⋆ u. Putting x = 0 gives
r(T(y, z)) = T(z + 2, y) (using T(z, 0) = z + 1 twice). With y = 0 this reads
r(r(z)) = z + 3. Hence, for all w, y,
T(w, y) = r(T(y, w − 2)) = r(r(T(w − 2, y − 2))) = T(w − 2, y − 2) + 3,
and by induction T(w, y) = T(w − 2k, y − 2k) + 3k for all k ≥ 0. If N is even
and N ≥ 2, k = N/2 gives 3N/2 ≡ 0 (mod N), i.e. N/2 ≡ 0, impossible. If N is
odd, choose k ≥ 0 with 2k ≡ y (mod N); then T(w, y) = T(w − 2k, 0) + 3k =
w + 1 + k, so the model is affine with a = 2^{−1}. Its affine system is
{a − 2, a² − 1, 2a − 1}; with 2a = 1 the polynomial a − 2 vanishes iff
3a ≡ 0, i.e. 3 ≡ 0 (mod N) after multiplying by 2. So N ∈ {1, 3}, and for N = 3,
a = 2 satisfies all three. ∎

*Proof of (b).* Putting z = 0 in the law gives x ⋆ (y + 1) = ((x ⋆ y) + 1) ⋆ x
(ii); x = 0 gives 0 ⋆ (y ⋆ z) = ((0 ⋆ y) ⋆ z) + 1 (iii). With z = 0, (iii) gives
0 ⋆ (y + 1) = (0 ⋆ y) + 2, so 0 ⋆ y = 1 + 2y for all y; substituting back into
(iii), (1 + 2y) ⋆ z = 2·(y ⋆ z) for all y, z (v). With y = 0, (v) gives
1 ⋆ z = 2(1 + 2z) = 2 + 4z. Now (ii) with x = 1 gives
1 ⋆ (y + 1) = (1 ⋆ y + 1) ⋆ 1 = (3 + 4y) ⋆ 1 = 2((1 + 2y) ⋆ 1) = 4 (y ⋆ 1)
by (v) twice, while the left side is 2 + 4(y + 1) = 6 + 4y. So
4(y ⋆ 1) = 6 + 4y for all y. At y = 0, 0 ⋆ 1 = 3 gives 12 ≡ 6; at y = 1,
1 ⋆ 1 = 6 gives 24 ≡ 10. Hence N divides 6 and 14, so N | 2. For N = 2 the
affine system {a − 2, a² − a, a} has the root a = 0, x ⋆ y = x + 1; it is the
only model, since 0 ⋆ y = 1 + 2y = 1 and 1 ⋆ z = 2 + 4z = 0 fix the table. ∎
(Lean, both parts: `law13_size_dvd_three`, `law13_model_three`, `law12_size_dvd_two`, `law12_model_two`.)

*Further cases.* The laws (xy)z = z((yx)z) and (xy)z = z((yz)x) also have
spectrum exactly {1, 3}, by short hand arguments: for the first, z = 0 and then
x = 0 give r(y + 2) = r(y) + 1 for the row r = 0 ⋆ ·, so N is odd and
r(y) = 1 + y/2; then 2(x ⋆ y) = (y ⋆ x) + 1, applied twice, gives
3(x ⋆ y) = 3, and y = 0, x = 1 gives 3 ≡ 0. For the second, the same start gives
2(x ⋆ y) = (y + 1) ⋆ x, whence 1 ⋆ x = 2x + 2, u ⋆ 1 = 4u and 2 ⋆ x = 8x, so
3 = 2 ⋆ 0 = 0. Theorem 6 below proves the upper bounds of 16 of the 17 laws of
CLM-C06-10 mechanically.

## Theorem 5 (CLM-C13-05) — a spectrum that is not closed under divisors

The law x = x ⋆ (x ⋆ (x ⋆ x)) has an anchored model of every size N ≠ 2 and none
of size 2. In particular it has a model of size 4 but not of size 2: anchored
spectra need not be closed under divisors (refuting H-C13-1).

*Proof.* N = 2: the anchor gives 0 ⋆ 0 = 1; if 0 ⋆ 1 = 0 then
0 ⋆ (0 ⋆ (0 ⋆ 0)) = 0 ⋆ 0 = 1, and if 0 ⋆ 1 = 1 then it is 0 ⋆ 1 = 1; either way
the law fails at x = 0. N ≥ 3: define 0 ⋆ 1 = 2, 0 ⋆ y = 0 for y ∉ {0, 1},
x ⋆ x = x for x ≠ 0, x ⋆ 0 = x + 1, and all other entries arbitrary (say 0). At
x = 0: 0 ⋆ 0 = 1, 0 ⋆ 1 = 2, 0 ⋆ 2 = 0 (as 2 ∉ {0, 1} when N ≥ 3). At x ≠ 0: the
diagonal entry is x three times. N = 1 is trivial. ∎ (Lean: `cube_law_no_two`,
`cubeOp_model`.)

*Remark (one-variable laws).* A one-variable law only relates, for each x,
table entries whose arguments are terms in x, so models are easy to build for
large N; but the anchor fixes column 0 (in particular 0 ⋆ 0 = 1), which can
exclude small sizes (as here) or force N | k: x = (⋯((x x) x)⋯) x with k + 1 leaves evaluates at x = 0
to 0 = k, and the table x ⋆ y = x + 1 shows that every divisor of k occurs, so
its spectrum is exactly Div(k). (This refutes H-C13-5, "every one-variable
law has spectrum {1} or a cofinite spectrum".)

## Theorem 6 (CLM-C13-06) — soundness of offset congruence closure

The procedure `offset_closure_bound` of `systems/anchored.py` returns an
integer g ≥ 0 such that, for every N and every anchored model of size N of the
given laws, N divides g (g = 0 asserts nothing).

*Proof.* The procedure manipulates expressions (s, k), meaning "the element
named s plus k", where s = 0 names the element 0 and every other symbol names
one table entry T(u, v) met during evaluation (u, v themselves expressions).
Fix a model of size N and interpret every symbol by the element it names; this
is well defined because a symbol is created for a specific pair of
already-interpreted arguments. Every equation the procedure records is true in
the model: (i) both sides of a law instance at interpreted elements are equal
(the law holds for all elements); (ii) T(u, 0) = u + 1 is applied only when the
right argument is literally the element 0 (anchor); (iii) when two keys become
equal after normalisation, their entries are equal (T is a function). The
union-find stores only consequences of recorded equations (s = root + offset is
obtained by composing true equations). When an equation relates a class to
itself, root + k₁ = root + k₂ holds in ℤ/N, so N | k₁ − k₂; g is the gcd of such
differences, hence N | g. Unknown coincidences (two different keys naming the
same element, or a non-literal argument equal to 0 modulo N) are never
assumed, only not exploited, which costs completeness but not soundness. ∎

*Corollary 6a (computer-assisted).* If the procedure returns g > 0 and every
divisor of g admits an affine model, the anchored spectrum is exactly Div(g).
This proves the spectra {1, 3} and {1, 2} for 16 of the 17 laws of CLM-C06-10
(all except x(yz) = y((yx)z)), see EXP-C13-08; the trust base is the closure
code, cross-checked against SAT on hundreds of laws without a single
contradiction.
