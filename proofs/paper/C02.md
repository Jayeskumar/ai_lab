# Cycle C02 — Written proofs

Setting. A configuration is a finitely supported vector c = (c_0, c_1, …) of
token counts per level (by C01, a multiset of levels = a word modulo
commutation). A **carry rule** (m; b_1, …, b_J) with m ≥ 1, b_j ≥ 0,
B = Σ b_j > 0 *fires* at a level k with c_k ≥ m: c_k −= m and c_{k+j} += b_j.
The carry polynomial is P(x) = Σ b_j x^j − m and r > 0 is its unique positive
root (Σ b_j x^j is increasing on x > 0). The *value* of c is
V(c) = Σ c_k r^k; every firing preserves V because Σ b_j r^{k+j} = m r^k.
A configuration is *stable* if every c_k < m. rep(n) denotes the stable
configuration reached from n tokens at level 0 (when it exists).

---

## Theorem 1 (CLM-C02-02) — the abelian property

If c → c′ (fire at k) and c → c″ (fire at l ≠ k), then firing l in c′ and k
in c″ gives the same configuration. Consequently, from any configuration
either every maximal derivation is infinite, or all are finite, end in the
same stable configuration, have the same length, and fire each level the same
number of times.

*Proof.* Firing at k only *removes* tokens from level k and adds tokens
elsewhere, so level l still holds ≥ m tokens in c′ (if l ≠ k); symmetrically
for c″. The result of firing both is c − m e_k − m e_l + Σ_j b_j (e_{k+j} +
e_{l+j}) in either order. This is the one-step diamond property; the standard
induction (on the length of a shortest complete derivation) gives the rest:
if c has a complete derivation of length L, then every maximal derivation from
c has length L, the same endpoint and the same firing multiset (Björner,
Lovász and Shor 1991 prove the same "strong convergence" for chip-firing). ∎

## Theorem 2 (CLM-C02-01) — integer bases

For the rule (b; 1) (b ≥ 2), rep(n) is the base-b expansion of n and every
complete derivation from n tokens has exactly (n − s_b(n))/(b − 1) firings,
s_b the base-b digit sum.

*Proof.* Each firing reduces the token count by b − 1, so derivations
terminate. The endpoint is stable (digits < b) and has value n with weights
r^k = b^k, hence is the base-b expansion (uniqueness of base-b expansions).
The final token count is s_b(n), so the number of firings is
(n − s_b(n))/(b − 1); by Theorem 1 all complete derivations agree. ∎

## Theorem 3 (CLM-C02-03) — termination dichotomy away from B = m

(a) If B < m, every derivation from every configuration terminates, after at
most (number of tokens)/(m − B) firings.
(b) If B > m, then r < 1, and for n > (m − 1)/(1 − r) no derivation from n
tokens at level 0 terminates.

*Proof.* (a) Each firing removes m − B ≥ 1 tokens. (b) f(x) = Σ b_j x^j
increases from 0 to B > m on [0, 1], so r < 1. A stable configuration has
value Σ c_k r^k ≤ (m − 1) Σ_{k≥0} r^k = (m − 1)/(1 − r). Since every firing
preserves the value n, no stable configuration is reachable when
n > (m − 1)/(1 − r). ∎

## Lemma 4 (part of CLM-C02-04) — the uniform glider for B = m

Let B = m and T_i = Σ_{j ≥ i} b_j (so T_1 = m). In the upward sweep, the
window W = (c_{k+1}, …, c_{k+J}) evolves by the monotone map
F(x_1, …, x_J) = (x_2 + t b_1, …, x_J + t b_{J−1}, t b_J), t = ⌊x_1/m⌋.
Then F(T) = T, and if a window U ≥ T (componentwise) ever occurs, the
derivation is infinite.

*Proof.* With x = T, t = 1 and F(T)_i = T_{i+1} + b_i = T_i. F is monotone
because ⌊·/m⌋ is. If U ≥ T then F^k(U) ≥ F^k(T) = T for all k, so the first
entry of every later window is ≥ T_1 = m and a firing happens at every later
level. ∎

*Conjecture (CLM-C02-04).* For every carry rule with B = m, some unary start
n reaches a window dominating T (or its g-sparse analogue, g = gcd of the
support of b); hence carry rules with B = m never terminate from all unary
starts. Verified for all 28 such rules with m ≤ 4, J ≤ 3, b_j ≤ 3: each run
reaches exactly the glider T (period 1) or its g-sparse version (period g).

## Theorem 5 (CLM-C02-05) — certificates for the surveyed rules (computer-assisted)

For each of the 158 carry rules with m ≤ 4, J ≤ 3, b_j ≤ 3 and B ≥ m there is
a unary start n ≤ 200 with an infinite derivation; for each of the 31 rules
with B < m every derivation terminates.

*Proof.* B < m: Theorem 3(a). B ≥ m: EXP-C02-03 exhibits for each rule a
window W with an entry ≥ m that recurs (periodic glider) or is later dominated
componentwise; by monotonicity of F (Lemma 4's argument) the firings never
stop. By Theorem 1 the sweep order is no loss of generality. ∎

## Theorem 6 (CLM-C02-08) — representations respect the radix order

For every carry rule with B < m and every n, rep(n) < rep(n+1) in radix order
(longer is larger; equal lengths compare from the highest level).

*Proof.* rep(n+1) is obtained by stabilising rep(n) + e_0 (Theorem 1). Let K
be the highest level whose count changes. Level K cannot have fired: a firing
at K sends b_j > 0 tokens to some level above K, which would then change.
So level K only received tokens and its count increased, while all levels
above K are unchanged. If the length grew, rep(n+1) is longer; otherwise the
first difference from the top is an increase at K. ∎

## Theorem 7 (CLM-C02-07) — uniqueness of representations

Let g = gcd{j : b_j > 0} and P̃(y) = Σ_i b_{gi} y^i − m (so P(x) = P̃(x^g)).
If P̃ is primitive (gcd(m, b_g, b_{2g}, …) = 1) and irreducible over ℚ, then
distinct stable configurations supported on gℕ have distinct values. In
particular rep(n) is the only stable configuration of value n supported on gℕ.

*Proof.* Writing configurations supported on gℕ as d(x^g), their values are
d(ρ) with ρ = r^g a root of P̃. The statement "two integer polynomials with
coefficients in [0, m) and equal value at a real root of a primitive,
ℚ-irreducible P̃ with constant term −m are equal" is machine-checked:
`Infinity.C02.digits_unique` (`proofs/lean/Infinity/C02_Exchange.lean`). The
idea: Δ = c − d vanishes at the root; over ℚ the irreducible P̃ either divides
Δ or is coprime to it, and a Bézout identity evaluated at the root rules out
coprimality; by Gauss's lemma P̃ | Δ in ℤ[x]; if Δ = P̃·Q ≠ 0 its trailing
coefficient is −m·(trailing coefficient of Q), of absolute value ≥ m, while
all coefficients of Δ are differences of digits, of absolute value < m.
Finally rep(n) is supported on gℕ because tokens starting at level 0 only
reach levels in gℕ. ∎

*Converse for non-primitive P̃ (Proposition).* If d = gcd(m, b_g, …) > 1, the
configurations "m/d tokens at level 0" and "b_{gi}/d tokens at level gi" are
both stable (all counts < m) and have equal value, since P̃(ρ)/d = 0.

*Remark.* The refuted H-C02-4 (EXP-C02-04) failed exactly for the rules where
P̃ is not primitive, or where uniqueness is asked off the reachable lattice
(rule 4[k] → [k+2], base 2 on all levels, digits 0..3).

## Theorem 8 (CLM-C02-09) — the Fibonacci exchange system (Zeckendorf game)

Rules (weights w_k = F_{k+2} = 1, 2, 3, 5, …): R1 [k]+[k+1] → [k+2];
R2 2[k] → [k+1]+[k−2] (k ≥ 2); R3 2[1] → [2]+[0]; R4 2[0] → [1].
From every configuration every derivation terminates, at the Zeckendorf
representation of the value. The shortest derivation from n tokens at level 0
has exactly n − z(n) steps, z(n) the number of Zeckendorf terms.

*Proof.* Values are preserved (2F_{k+2} = F_{k+3} + F_k etc.), and there are
finitely many configurations of a given value. R1 and R4 lower the token
count; R2 and R3 keep it and strictly lower M = Σ c_k g(k) with g(0) = −1/2,
g(k) = k (k ≥ 1) (changes −3/2 at k = 2, −1 at k ≥ 3, −1/2 for R3). A cycle
would keep the count constant, hence use only R2/R3, hence strictly lower M —
impossible; so every derivation terminates. A stable configuration has no
level with two tokens and no adjacent occupied levels, i.e. it is a Zeckendorf
representation, unique by Zeckendorf's theorem.
Shortest length: R1/R4 each lower the count by one, so every complete
derivation has at least n − z(n) steps. Conversely, add tokens one at a time:
merging a token into a Zeckendorf configuration needs only R4/R1 cascades,
because each merge [k]+[k+1] → [k+2] lands on level k+2, which was empty (k+1
was occupied), so no level ever holds two tokens. This strategy uses exactly
n − z(n) steps. ∎

*Literature.* This system is the *Zeckendorf game* of Baird-Smith, Epstein,
Flint and Miller (arXiv:1809.04881), where the shortest game N − Z(N) and
termination are proved; the longest game is studied by Cusenza et al.
