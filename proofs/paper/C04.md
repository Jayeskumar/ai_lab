# Cycle C04 — Written proofs

Setting. A one-rule system is a rule l → r with l ≠ r over an alphabet Σ
(mostly {a, b}); a step rewrites one occurrence: x l y → x r y. A word is a
*normal form* if it contains no occurrence of l. D(w) denotes the maximal and
d(w) the minimal number of steps from w to a normal form; the *derivational
complexity* is D(n) = max_{|w| = n} D(w). *Random descent* (RD, van Oostrom):
for every w, all maximal derivations from w have the same length and end in
the same normal form. A word b is a *border* of l if 0 < |b| < |l| and b is
both a prefix and a suffix of l; l is *unbordered* if it has no border.

Lean file: `proofs/lean/Infinity/C04_Derivations.lean` (Lean 4 + Mathlib,
standard axioms only).

## Theorem 1 (CLM-C04-01) — termination census for |l|, |r| ≤ 3

Of the 196 rules over {a, b} with 1 ≤ |l| ≤ 3, 0 ≤ |r| ≤ 3, exactly 34 are
non-terminating, namely those where l is a factor of r; the other 162
terminate.

*Proof (computer-assisted, EXP-C04-01).* If l is a factor of r then
l → r contains l, an explicit self-embedding, so the system is
non-terminating. Each of the other 162 rules has a certificate checked by the
program: |r| < |l| (length decreases; 70 rules); |r| = |l| (length-preserving:
every step changes the word first at the same offset of the window in the
same direction, so steps are monotone in the lexicographic order of the finite
set Σ^{|w|}; 70 rules); a strictly monotone linear interpretation
a ↦ c_a x + d_a, b ↦ c_b x + d_b over ℕ with [l](x) > [r](x) for all x ≥ 0
(20 rules, e.g. ab → bba with a ↦ 3x, b ↦ x + 1); or a factor whose number of
occurrences drops by at least one at every step in every context (2 rules:
aa → aba and bb → bab, factor aa resp. bb; only contexts of length ≤ |f| − 1
on each side can affect the count, and all of them are checked). ∎

*Remark.* The extended census (EXP-C04-02, |r| ≤ 5) shows the pattern is not a
law: **ab → bbaa is non-terminating** although ab is not a factor of bbaa:
aab → a·bbaa = abbaa → bbaa·baa = bb·aab·aa (CLM-C04-02, refuting H-C04-0).
Eight rules of the extended census (two symmetry classes, aab → ababa and
aab → babaa) remain undecided (CLM-C04-03).

## Theorem 2 (CLM-C04-06) — every one-rule system has a constant-step potential

For every rule l → r (l ≠ r) there are Φ : Σ* → ℤ and δ ≠ 0 with
Φ(v) = Φ(u) + δ for every step u → v. Consequently

1. all derivations from u to v have the same number of steps, (Φ(v) − Φ(u))/δ;
2. a terminating one-rule system is confluent iff it has random descent.

*Proof.* If |l| ≠ |r| take Φ(w) = |w| and δ = |r| − |l|. Otherwise
|l| = |r| = k. Pick j with l_j ≠ r_j and let c = l_j; the position sets
P = {j : l_j = c} and Q = {j : r_j = c} ⊆ {0, …, k − 1} differ. Their indicator
vectors differ, and the power sums p_m(S) = Σ_{j ∈ S} j^m (m = 0, …, k − 1,
with 0^0 = 1) are the image of the indicator vector under the invertible
Vandermonde matrix (j^m), so p_m(P) ≠ p_m(Q) for some m. Let K be the least
such m and put Φ(w) = Σ_{i : w_i = c} i^K. A step at offset i₀ only changes
positions i₀, …, i₀ + k − 1, and

ΔΦ = Σ_{j∈Q} (i₀ + j)^K − Σ_{j∈P} (i₀ + j)^K
   = Σ_{m=0}^{K} C(K, m) i₀^{K−m} (p_m(Q) − p_m(P)) = p_K(Q) − p_K(P) =: δ ≠ 0,

because the differences vanish for m < K. This δ does not depend on i₀ or on
the context.
(1) Along n steps Φ changes by nδ (Lean: `potential_steps`,
`steps_length_unique`; the length-changing case is `length_changing_unique`).
(2) RD ⇒ confluence: in a terminating system each word then has a unique
normal form, and any two reducts of u reduce to that normal form. Confluence ⇒
RD: every maximal derivation from u is finite and ends in the unique normal form
ν(u), and by (1) all of them have length (Φ(ν(u)) − Φ(u))/δ. ∎

*Corroboration.* EXP-C04-06 builds (c, K, δ) for 5365 rules (binary
|l|, |r| ≤ 5, ternary ≤ 3) and checks ΔΦ = δ on 470,927 steps (0 violations;
K ≤ 2 sufficed). Among 770 bordered length-preserving binary rules with
|l| = 4, 5, all 94 confluent ones are length-uniform; conversely 126 rules are
length-uniform but *not* confluent (e.g. aaaba → baabb on aaabaaaba reaches two
normal forms in one step each) — length uniformity is strictly weaker than RD.

## Theorem 3 (part of CLM-C04-05) — the local criterion for random descent

If every local peak b ← a → c is joinable by two derivations of equal length,
then whenever a reaches a normal form b in n steps, every derivation from a
has at most n steps, and every derivation from a to a normal form has exactly
n steps and ends in b.

*Proof.* Machine-checked: `Infinity.C04.random_descent`. Induction on n; for
a → a₁ →ⁿ⁻¹ b and another step a → a₂, the equal-length join a₁ →ᵏ d ←ᵏ a₂
and the induction hypothesis at a₁ show that d reaches b in n − 1 − k steps,
hence a₂ reaches b in n − 1 steps, and the hypothesis applies at a₂. This is
van Oostrom's local characterisation of random descent (RTA 2007). ∎

## Theorem 4 (CLM-C04-05) — unbordered left-hand sides give random descent

If l is unbordered, two distinct one-step reducts of a word have a common
one-step reduct; hence l → r has random descent.

*Proof.* Machine-checked: `Infinity.C04.unbordered_diamond`,
`Infinity.C04.unbordered_random_descent`. Two occurrences of l in
x₁ l y₁ = x₂ l y₂ either coincide, are disjoint (then rewrite the other one),
or overlap; an overlap with offset a ≠ ε writes l = a c with c a nonempty
proper suffix that is also a prefix of l, i.e. a border — impossible. Then
apply Theorem 3. ∎

*Refutation of the converse (CLM-C04-07, H-C04-1).* aa → a has the bordered
left-hand side aa but random descent: every step shortens a run of a's by one,
so every derivation from w has exactly Σ_runs (len − 1) steps and ends in the
same word. Eighteen bordered rules with |l|, |r| ≤ 3 have RD (EXP-C04-05).

## Theorem 5 (CLM-C04-04) — the rule ab → ba

Every step lowers the number of inversions inv(w) (pairs "a before b") by
exactly one; the normal forms are the words b…ba…a; every complete derivation
from w has exactly inv(w) steps; D(n) = ⌊n²/4⌋; and in the rewriting game the
P-positions are exactly the words with an even number of inversions.

*Proof.* Lean: `inv_step`, `normal_iff_inv_zero`, `derivation_length_eq_inv`,
`p_positions` (the even-inversion words form a kernel of the game graph: every
move leaves it, and from outside some move enters it; for a terminating game
the kernel is the set of P-positions). D(n) = max_k k(n − k) = ⌊n/2⌋⌈n/2⌉. ∎
This is the classical extremal case of Métivier's conjecture, proved by
Bertrand (TCS 1994): length-preserving one-rule systems have derivation
length ≤ n²/4, attained by ba → ab.

## Theorem 6 (part of CLM-C04-12) — the doubling rules

For ab → bba and ab → baa (and their mirror images), D(n) = 2^{n−1} − 1.

*Proof (ab → bba).* The left-hand side is unbordered, so all derivations from w
have the same length. Reading w from right to left with B = number of b's
already met: an a that meets B b's crosses them in B steps and leaves 2B b's
behind it. Hence D(w) is computed by the scan "b: B += 1; a: D += B, B *= 2".
For k a's and m b's the value is maximal when all b's come last (moving a b
to the right of an a never decreases any later contribution), giving
m(2^k − 1), and m(2^{n−m} − 1) is maximal at m = 1. The scan agrees with the
exhaustive derivation graphs on all 2,044 words of length ≤ 8 (EXP-C04-03).
ab → baa is symmetric. ∎

## Theorem 7 (CLM-C04-09) — aab → ba has complexity n − log₂ n + O(1)

D(n) = n − 1 − κ(n) for n ≥ 1, where κ(n) = min{k ≥ 0 : 2^k + k ≥ n}.
D stalls (D(n) = D(n − 1)) exactly at n = 2^k + k + 1, and Σ D(n)xⁿ is not a
rational function.

*Proof.* (i) *Encoding.* Write w = a^{x₀} b a^{x₁} b ⋯ b a^{x_m}. An occurrence
of aab ends at the (k+1)-th b and needs x_k ≥ 2; rewriting it gives
x_k − 2 a's before that b and x_{k+1} + 1 after it. So the system is the
exchange system "2 tokens at level k → 1 token at level k+1" (k < m) of cycle
C02, with level m inert.
(ii) aab is unbordered, so all derivations from w have the same length (Thm 4),
and each step removes one token: D(w) = T − T_final, T = Σ x_k = n − m.
(iii) Steps preserve V = Σ x_k 2^k. The stable configuration (≤ 1 token on
each level k < m) of value V is unique: binary digits of V mod 2^m below m and
⌊V/2^m⌋ tokens on level m. Hence D(w) = T − s₂(V mod 2^m) − ⌊V/2^m⌋.
(iv) For fixed m and T ≥ 1 the maximum over w is T − ⌈T/2^m⌉. Write
V = q 2^m + ρ, 0 ≤ ρ < 2^m; V ≥ T since every token weighs ≥ 1. If ρ = 0 then
q ≥ ⌈T/2^m⌉; if ρ > 0 then s₂(ρ) ≥ 1 and q > T/2^m − 1, so
s₂(ρ) + q ≥ ⌈T/2^m⌉ in both cases. Equality: start with q = ⌈T/2^m⌉ tokens on
level m and split tokens (one token on level j ≥ 1 into two on level j − 1)
until there are T tokens; possible because q ≤ T ≤ q 2^m.
(v) So n − D(n) = f(n) := min_m (m + ⌈(n − m)/2^m⌉). For k ≥ 0, f(n) ≤ k + 1 iff
n ≤ 2^k + k: "if" with m = k; "only if" because m ≥ k + 1 forces n ≤ k + 1, and
for m ≤ k the condition gives n ≤ g(m) := m + (k + 1 − m)2^m with
g(m + 1) − g(m) = 1 + 2^m(k − m − 1) ≥ 0, so g(m) ≤ g(k) = 2^k + k. Therefore
f(n) = 1 + κ(n) and D(n) = n − 1 − κ(n); the jumps of κ, i.e. the stalls of D,
are at n = 2^k + k + 1.
(vi) If Σ D(n)xⁿ were rational, so would be the 0/1 sequence
e(n) = κ(n) − κ(n − 1). It would satisfy a linear recurrence of some order d
from some point on; its length-d windows take finitely many values, so two
windows coincide and the recurrence makes e eventually periodic. But e = 1
exactly on {2^k + k + 1}, whose gaps are unbounded. ∎

*Corroboration.* Exhaustive graphs (n ≤ 17), one derivation per word for all
words of length ≤ 21 (per-word configuration formula: 0 mismatches), closed
form checked to n = 20000 (EXP-C04-03, EXP-C04-04).

## Theorem 8 (CLM-C04-10) — an unexpected identity with OEIS A247983

Let A(n) be the least k ≥ 1 with log 2 − Σ_{h=1}^{k} 1/(h 2^h) < 2^{−n}
(OEIS A247983, offset 1). Then for every n ≥ 1, A(n) = n − J(n) with
J(n) = max{j ≥ 0 : 2^j + j ≤ n + 1}, and A(n) = D(n + 2) for the rule aab → ba.
(At n = 0 the identity fails: A(0) = 1 but D(2) = 0; the proof below uses
k* = n − J ≥ 1, which needs n ≥ 1 — skeptic review 2026-10-18.)

*Proof.* t(k) := log 2 − Σ_{h≤k} 1/(h2^h) = 2^{−k} Σ_{i≥1} 2^{−i}/(k + i). The
weights 2^{−i} sum to 1 with mean Σ i2^{−i} = 2, so by Jensen (1/x convex)
2^{−k}/(k + 2) ≤ t(k), and t(k) < 2^{−k}/(k + 1) since 1/(k + i) < 1/(k + 1)
for i ≥ 2. Let J = J(n), k* = n − J ≥ 1. Then n − J + 1 ≥ 2^J gives
t(k*) < 2^{J−n}/(n − J + 1) ≤ 2^{−n}. For k = k* − 1,
t(k) ≥ 2^{J+1−n}/(n − J + 1) ≥ 2^{−n} because maximality of J gives
2^{J+1} + J + 1 ≥ n + 2. As t decreases, A(n) = k*. Finally
κ(n + 2) = min{k : 2^k + k ≥ n + 2} = J(n) + 1 (2^k + k is increasing), so
D(n + 2) = n + 1 − κ(n + 2) = n − J(n). ∎

*Corroboration.* A(n) computed with n + 80 bits for n ≤ 1500: 0 mismatches
(EXP-C04-10); the OEIS entry lists no formula.

## Theorem 9 (CLM-C04-08) — parity for random-descent games

If a rule has random descent, the Sprague–Grundy value of the rewriting game
at w is D(w) mod 2; the P-positions are the words with D(w) even.

*Proof.* By induction on D(w): every option v of w satisfies
D(v) = D(w) − 1 (any maximal derivation through v has length 1 + D(v)), so
g(w) = mex{(D(w) − 1) mod 2} = D(w) mod 2. ∎ (EXP-C04-07: 0 violations over
all 102 RD rules and all words of length ≤ 10.)

## Theorem 10 (CLM-C04-13) — unary left-hand sides give take-and-break games

For a terminating rule a^k → u, the rewriting game on w is the disjoint sum of
games on the maximal a-runs of w; on a run of length n a move at offset
0 ≤ i ≤ n − k produces the runs i + e₀, e₁, …, e_{t−1}, n − k − i + e_t, where
u = a^{e₀} b⋯ b a^{e_t} (or the single run n − k + |u| if u ∈ a*). In
particular aa → b (also bb, bbb, bab) is **Dawson's Kayles** (octal 0.07),
aa → ab (also ba, abb, bba) is **Officers** (0.6), aaa → b (bb, bbb, bab) is
**0.007 = Treblecross**, aaa → ab (ba, abb, bba) is **0.06**, aaa → aba is
**0.4**.

*Proof.* Occurrences of a^k lie inside single a-runs, the b's of u and of w are
never rewritten, and the rewritten run is replaced by the listed runs
separated by b's; runs never merge. So the game graph of w is the product of
the run games, and g(w) is the XOR of the run values (Sprague–Grundy). Middle
runs e_j < k are dead. Reading off which heaps a move may leave gives the
octal codes (e.g. for aa → ab: remove one token, leaving one heap n − 1 ≥ 1 or
two nonempty heaps — octal digit 6). ∎ (EXP-C04-07: 58 unary rules, all words
≤ 10; EXP-C04-08: word games on a^n = run games for n ≤ 20 and = octal
recursions for n ≤ 3000.) Dawson's Kayles has period 34 from n₀ = 53; the
Guy–Smith window n₀ ≤ n < 2n₀ + p + t was checked explicitly. These are the
standard "pins in a row" descriptions of octal games — a rediscovery.

*Refutation (CLM-C04-14, H-C04-6).* The single word a^{14} has Grundy value 4
under aa → b (computed directly from its derivation graph).
