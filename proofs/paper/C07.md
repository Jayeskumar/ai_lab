# Cycle C07 — Written proofs (arithmetic from the minimal excludant)

Setting. mex(S) is the least natural number not in S (mex ∅ = 0). A *mex
operation* with spec (L, R, D) is defined by recursion on (a, b):
f(a, b) = mex V(a, b), where V(a, b) contains f(a′, b) for all a′ < a if L,
f(a, b′) for all b′ < b if R, and, for every a′ < a, b′ < b and every mask in
D, the XOR of the selected values among x = f(a′, b), y = f(a, b′),
z = f(a′, b′). The recursion determines f uniquely. Conway's nim-sum is L + R,
his nim-product is D[x⊕y⊕z]. Code: `systems/mex.py`.

We repeatedly use two classical facts (Conway, *On Numbers and Games*):
(N1) for all α, β the set {α′ ⊕ β : α′ < α} ∪ {α ⊕ β′ : β′ < β} contains every
natural number below α ⊕ β and not α ⊕ β; (N2) the same holds for
{α′ + β : α′ < α} ∪ {α + β′ : β′ < β} ∪ {α′ + β′ : α′ < α, β′ < β} and α + β
(every v < α + β is α′ + β with α′ = v − β if v ≥ β, else α + β′ if v ≥ α, else
v + 0 with v < α, 0 < β; and every listed value is < α + β).

## Theorem 1 (CLM-C07-01) — the associative mex operations

(a) The following canonical specs define, for all a, b ∈ ℕ, the stated
operations (all associative):

| spec | f(a, b) |
|---|---|
| empty | 0 |
| L | a |
| R | b |
| D[x] | a if b > 0, else 0 |
| D[y] | b if a > 0, else 0 |
| D[z] | min(a, b) |
| L + R | a ⊕ b (nim-sum; Conway) |
| D[x⊕y⊕z] | a ⊗ b (nim-product; Conway) |
| L + R + D[z] | a + b |
| D[x] + D[y] | 0 if a = 0 or b = 0, else ((a − 1) ⊕ (b − 1)) + 1 |
| D[x] + D[y] + D[z] | 0 if a = 0 or b = 0, else a + b − 1 |

(b) Of the 512 specs, 468 define non-associative operations, each certified by
an explicit triple (a, b, c) ∈ [0, 64)³ with f(f(a, b), c) ≠ f(a, f(b, c))
(EXP-C07-01). The remaining 44 specs coincide on [0, 64)² with one of the 11
operations of (a).

*Proof of (a).* By induction on (a, b); in each case we show that the claimed
formula F satisfies F(a, b) = mex V_F(a, b), where V_F is computed from F.
*empty:* V = ∅. *L:* V = {F(a′, b) : a′ < a} = {0, …, a − 1}. *R:* symmetric.
*D[x]:* if b = 0 there are no pairs (a′, b′), so V = ∅; if b > 0,
V = {F(a′, b) : a′ < a} = {0, …, a − 1}. *D[y]:* symmetric. *D[z]:*
V = {min(a′, b′) : a′ < a, b′ < b} = {0, …, min(a, b) − 1}. *L + R* and
*D[x⊕y⊕z]:* Conway's definitions of nim-addition and nim-multiplication.
*L + R + D[z]:* V is the set of (N2) with α = a, β = b, so mex V = a + b.
*D[x] + D[y]:* for a = 0 or b = 0 there are no pairs, so F = 0. For a, b ≥ 1
put α = a − 1, β = b − 1; since F(0, b) = F(a, 0) = 0,
V = {0} ∪ ({α′ ⊕ β : α′ < α} ∪ {α ⊕ β′ : β′ < β}) + 1, which by (N1) contains
0, 1, …, α ⊕ β and not α ⊕ β + 1. *D[x] + D[y] + D[z]:* likewise
V = {0} ∪ (the set of (N2) for α, β) + 1, whose mex is α + β + 1 = a + b − 1.
Associativity: 0, projections, min, +, ⊕, ⊗ are classical; a·[b > 0]
satisfies (ab)c = a·[b > 0][c > 0] = a(bc); the last two are the operations ⊕
and + on ℕ transported along n ↦ n + 1 with an absorbing element 0 adjoined. ∎

*Proof of (b).* Computer-assisted: the tables are exact (the vectorised mex is
cross-checked against a plain implementation), and a violating triple is a
proof of non-associativity. ∎

*Status of the other 33 specs.* They agree with the 11 operations on
[0, 64)²; we did not prove agreement for all a, b. So: at least 11 and at most
44 specs are associative, and every associative one is one of the 11
operations on [0, 64)².

## Theorem 2 (CLM-C07-03) — 0 is an identity or absorbing

If a spec contains both L and R, then f(0, b) = b and f(a, 0) = a; if it
contains neither, f(0, b) = f(a, 0) = 0.

*Proof.* With a = 0 there are no pairs (a′, b′) and no a′ < 0, so
V(0, b) = {f(0, b′) : b′ < b} if R, and ∅ otherwise; induction gives
f(0, b) = b, resp. 0. Symmetric in a. ∎

## Theorem 3 (CLM-C07-05) — the Jacobsthal row

Let f be the mex operation D[x⊕y], f(a, b) = mex{f(a′, b) ⊕ f(a, b′) :
a′ < a, b′ < b}, and let J_0 = 0, J_1 = 1, J_{k+1} = J_k + 2J_{k−1} be the
Jacobsthal numbers (1, 1, 3, 5, 11, 21, 43, …). Then f(0, b) = 0,
f(1, b) = b, and the second row g(b) = f(2, b) satisfies g(0) = 0 and, for
every k ≥ 1,

  g(b) = b + J_k  for 2^k − J_k ≤ b < 2^k,
  g(b) = b − J_k  for 2^k ≤ b < 2^k + J_k.

So g is the involution of ℕ that exchanges the blocks [2^k − J_k, 2^k) and
[2^k, 2^k + J_k) by translation; |g(b) − b| = J_k is unbounded, and the row is
not additively periodic.

*Facts used.* J_k = (2^k − (−1)^k)/3, hence (J1) J_{k+1} + J_k = 2^k, so
2^k − J_k = J_{k+1} and 2^k + J_k = J_{k+2}; (J2) J_k < 2^{k−1} for k ≥ 1 and
J_{k+1} > 2^{k−1} for k ≥ 2. (X) If 0 ≤ x < c then x ⊕ (x + c) > x: the
highest bit of x + c lies above the highest bit of x (if c and x had the same
highest bit h, then x + c ≥ 2^{h+1}), so x ⊕ (x + c) has a bit above every bit
of x.

*Proof.* Row 0: there is no a′ < 0, so f(0, b) = 0. Row 1: the options are
f(0, b) ⊕ f(1, b′) = f(1, b′), so f(1, b) = mex{f(1, b′) : b′ < b} = b. Row 2:
the options are f(a′, b) ⊕ g(b′) for a′ ∈ {0, 1}, i.e. G ∪ (b ⊕ G) with
G = {g(b′) : b′ < b}. Hence

  g(b) = min{v : v ∉ G and v ⊕ b ∉ G}.   (∗)

For b ≤ 4 the formula is checked directly from (∗): g = 0, 2, 1, 4, 3. Now let
k ≥ 3 and assume the formula below b. The blocks for j < k together with 0
fill [0, J_{k+1}), and g maps each block pair [J_{j+1}, J_{j+2}) onto itself,
so the values used before the k-th pair are exactly [0, J_{k+1}).

*Case b = J_{k+1} + t, 0 ≤ t < J_k (first block).* Then
G = [0, J_{k+1}) ∪ [2^k, 2^k + t). Claim g(b) = 2^k + t = b + J_k.
(i) Every v < 2^k + t is excluded. If v < J_{k+1} or v ≥ 2^k, then v ∈ G. If
J_{k+1} ≤ v < 2^k, write v = M − v̄ and b = M − b̄ with M = 2^k − 1 and
v̄, b̄ < J_k; then v ⊕ b = v̄ ⊕ b̄ < 2^{k−1} < J_{k+1} by (J2), so v ⊕ b ∈ G.
(ii) v = 2^k + t is allowed: v ∉ G, and v ⊕ b = 2^k + (t ⊕ (t + J_{k+1})),
where t ⊕ (t + J_{k+1}) > t by (X) because t < J_k ≤ J_{k+1}; so v ⊕ b lies
above 2^k + t and outside G.
*Case b = 2^k + t, 0 ≤ t < J_k (second block).* Now the first block is
complete, so G = [0, J_{k+1} + t) ∪ [2^k, J_{k+2}). Claim
g(b) = J_{k+1} + t = b − J_k. (i) Every v < J_{k+1} + t lies in G. (ii)
v = J_{k+1} + t < 2^k is not in G, and v ⊕ b = 2^k + ((J_{k+1} + t) ⊕ t). By
(J2), J_{k+1} + t ∈ (2^{k−1}, 2^k) has bit k − 1 set while t < J_k < 2^{k−1}
does not, so (J_{k+1} + t) ⊕ t ≥ 2^{k−1} > J_k and v ⊕ b ≥ J_{k+2}, outside G.
*Not additively periodic.* Suppose g(b + p) = g(b) + s for all b ≥ b_0. Then
h(b) = g(b) − b satisfies h(b + np) = h(b) + n(s − p). If s = p, h is bounded
beyond b_0, but |h| = J_k on the k-th block pair. If s > p, every residue class
mod p eventually has h > 0, but for large k the block [2^k, J_{k+2}) has length
J_k ≥ p, lies beyond all those points and has h = −J_k < 0. If s < p, argue
symmetrically with the first block, where h = +J_k > 0. ∎

*Corroboration.* An independent bitset implementation of (∗) agrees with the
mex table for b < 1500 and with the formula for all b < 2^15 (EXP-C07-03).

## Refutations

* *H-C07-1* (only nim-sum and nim-product, apart from trivial operations, are
  associative) — refuted by L + R + D[z] = a + b and D[z] = min (Theorem 1).
* *H-C07-2* (commutative mex operations are closed on [0, 2^{2^m})) — refuted:
  for D[x⊕y], f(2, 3) = 4 ∉ [0, 4) (Theorem 3); 30 of the 34 commutative
  operations fail on [0, 2), [0, 4) or [0, 16) (EXP-C07-01).
* *H-C07-4* (all rows eventually additively periodic) — refuted by Theorem 3;
  numerically only 222 of 670 rows (a = 1..5, b < 1500) show a period ≤ 375.
