# Cycle C08 — Written proofs

Notation. F_k are the Fibonacci numbers with F_0 = 0, F_1 = F_2 = 1 (Mathlib
indexing). Every n ≥ 0 has a unique Zeckendorf set Z(n) of indices ≥ 2, no
two consecutive, with n = Σ_{k∈Z(n)} F_k. φ = (1+√5)/2 and ψ = (1−√5)/2 are
the roots of x² = x + 1; φψ = −1, φ + ψ = 1, φ − ψ = √5, −1 < ψ < 0,
ψ² = ψ + 1 ≈ 0.382, −ψ = φ^{-1} ≈ 0.618.

For t ≥ 0 the shifted Knuth product is
a ∘_t b = Σ_{k∈Z(a)} Σ_{l∈Z(b)} F_{k+l+t}.
(t = 0 is Knuth's Fibonacci multiplication. In the lab's G-indexing,
G_i = F_{i+2} and shift s, one has s = t + 2.)

## Theorem 1 (CLM-C08-01) — every shifted Knuth product is associative

For every t ≥ 0, ∘_t is associative (and commutative). For s ∈ {0, 1}
(i.e. "t = −2, −1") associativity fails: in G-indexing, (2∘4)∘4 ≠ 2∘(4∘4)
for s = 0 and (1∘4)∘4 ≠ 1∘(4∘4) for s = 1 (EXP-C08-01).

*Proof.* (1) For k ≥ 1, φ^k = F_k φ + F_{k−1} and ψ^k = F_k ψ + F_{k−1}
(Mathlib: `goldenRatio_mul_fib_succ_add_fib`, `goldenConj_mul_fib_succ_add_fib`).

(2) For a finite set K of indices ≥ 1 put v(K) = Σ F_k, h(K) = Σ F_{k−1},
A(K) = Σ φ^k, A′(K) = Σ ψ^k. By (1), A(K) = v(K)φ + h(K) and
A′(K) = v(K)ψ + h(K).

(3) *Window lemma.* If K is a finite set of integers ≥ 2 then
−ψ² < A′(K) < −ψ. Indeed ψ^k = (−1)^k φ^{−k}, so A′(K) is a sum of positive
terms φ^{−k} over even k ∈ K minus a sum over odd k ∈ K. The positive part is
< Σ_{j≥1} φ^{−2j} = 1/(φ² − 1) = 1/φ = −ψ, and the negative part is
> −Σ_{j≥1} φ^{−(2j+1)} = −1/φ² = −ψ²; both inequalities are strict because K
is finite. (Equivalently, by induction on min K with the bounds
U(m), L(m) = −ψ^{m−1}, −ψ^{m} for even m and −ψ^{m}, −ψ^{m−1} for odd m.)

(4) For n ≥ 0 write n* = h(Z(n)). Then A(Z(n)) = nφ + n*, A′(Z(n)) = nψ + n*,
and −ψ² < nψ + n* < −ψ.

(5) Fix a, b and put P = a ∘_t b. Using (1) with indices k + l + t ≥ 4,
φ^t A(Z(a)) A(Z(b)) = Σ_{k,l} φ^{k+l+t} = Pφ + Q and
ψ^t A′(Z(a)) A′(Z(b)) = Pψ + Q, with Q = Σ_{k,l} F_{k+l+t−1} ∈ ℕ.

(6) By (4), x = A′(Z(a)) and y = A′(Z(b)) lie in (−ψ², −ψ), so
xy ∈ (ψ³, ψ²) ⊂ (−ψ², ψ²) and, as |ψ^t| ≤ 1, Pψ + Q ∈ (−ψ², ψ²).

(7) By (4), Pψ + P* ∈ (−ψ², −ψ). Subtracting,
Q − P* ∈ (−ψ² + ψ, ψ² + ψ²) = (−1, 2ψ²) ⊂ (−1, 1), so the integer Q − P*
is 0.

(8) Therefore A(Z(a ∘_t b)) = φ^t A(Z(a)) A(Z(b)) and
A′(Z(a ∘_t b)) = ψ^t A′(Z(a)) A′(Z(b)): the maps n ↦ A(Z(n)), A′(Z(n)) turn
∘_t into multiplication twisted by φ^t, ψ^t.

(9) Applying (8) twice, A(Z((a∘b)∘c)) = φ^{2t} A(Z(a))A(Z(b))A(Z(c)) =
A(Z(a∘(b∘c))), and likewise for A′. If A(Z(x)) = A(Z(y)) and
A′(Z(x)) = A′(Z(y)), subtracting the two expressions in (4) gives
(x − y)(φ − ψ) = 0, so x = y. Hence (a∘b)∘c = a∘(b∘c). ∎

*Machine check.* The theorem is formalised in Lean 4 + Mathlib
(`proofs/lean/Infinity/C08_Knuth.lean`: `window`, `key`, `circ_assoc`,
`circ_comm`). The formal proof uses the symmetric window |Σ ψ^k| < −ψ (proved
by induction along the gap-≥2 chain of Zeckendorf indices, closing because
(−ψ) + ψ² = 1) instead of the sharper (−ψ², −ψ) of step (3); this suffices
because the product conjugate then satisfies |·| < ψ² and
|Q − P*| < ψ² + (−ψ) = 1. The sharper window of step (3) is used in C09.

*History.* t = 0 is Knuth (1988), with a second proof by Arnoux (1989) via
ℤ[φ]; the argument above is Arnoux's idea with the explicit window of step
(3). The extension to all shifts t ≥ 0 is immediate from the same window.

## Conjecture 2 (CLM-C08-02) — non-Pisot base sequences are never associative

If the minimal recurrence of a base sequence G has a characteristic root
β ≠ α (α the dominant root) with |β| ≥ 1, then ∘_s is non-associative for
every shift s.

*Evidence.* 10 non-Pisot sequences × shifts 0..8: no associative shift
(EXP-C08-02). *Heuristic.* The conjugate coordinate of
α^s ν(a) ν(b) is multiplied by β^s, which does not shrink, so it cannot be
forced back into the window of greedy expansions.

## Theorem/Rediscovery 3 (CLM-C08-03) — eventual associativity for Pisot sequences

For Pisot base sequences satisfying the conditions of Grabner, Pethő, Tichy
and Woeginger ("Associativity of recurrence multiplication", Appl. Math.
Lett. 7 (1994)), the product is associative once the shift parameter is
large enough. *Our role:* computational confirmation; thresholds measured for
45 sequences (EXP-C08-02/03). Not re-proved here beyond Theorem 1.

## Conjecture 4 (CLM-C08-04) — sign of the conjugate and monotonicity

For quadratic Pisot sequences with real conjugate β > 0, the set of
associative shifts is upward-closed; non-upward-closed sets occur only for
β < 0. *Mechanism (heuristic):* the product's conjugate coordinate is
multiplied by β^s; for β < 0 its sign alternates with s, and the window of
greedy expansions is asymmetric about 0 (for Fibonacci: (−ψ², −ψ)), so an odd
shift can push the product's conjugate out of the window while the next even
shift brings it back. *Evidence:* 30/30 positive-β sequences upward-closed;
10/60 negative-β sequences not (EXP-C08-04).
