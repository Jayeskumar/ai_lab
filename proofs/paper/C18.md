# Cycle C18 — Written proofs (quasigroup string transformations as mixing primitives)

Setting. Q is a quasigroup on the byte alphabet {0, …, 255} (a Latin square
T, x * y = T[x, y]). The *e-transformation* with leader l maps a_0 … a_{n−1}
to b_0 … b_{n−1}, b_0 = l * a_0, b_i = b_{i−1} * a_i (Markovski, Gligoroski,
Bakeva 1999). The hashes of EXP-C18-02..05 (code `systems/quasigroup_hash.py`):

* **QG(T, p, rev)** — message M = key ‖ (len mod 256) ‖ zero padding to ≥ 8
  bytes; p forward e-transformations; optionally one e-transformation of the
  reversed string; output = the last 8 bytes;
* **QC(T, d)** — the *cascade*: d = 8 e-transformations run in parallel over
  key ‖ len ‖ 0⁸, i.e. for each byte x: s_1 ← s_1 * x, s_j ← s_j * s_{j−1}
  (j = 2..8); output = (s_1, …, s_8).

Lean: `proofs/lean/Infinity/C18_Quasigroups.lean` (5 theorems, standard axioms
only). **Nothing below is a security evaluation.**

---

## Theorem 1 (CLM-C18-01) — e-transformations are bijections

For every leader l and every n, e_l : Q^n → Q^n is a bijection; its inverse is
the d-transformation a_0 = l \ b_0, a_i = b_{i−1} \ b_i (left division). Hence
every composition of forward and reversed e-transformations is a bijection of
Q^n.

*Proof.* Left cancellation gives injectivity (Lean `eT_injective`), the
length is preserved (`eT_length`), and an injective map of the finite set Q^n
into itself is bijective. The d-transformation inverts e_l by definition of
left division. ∎ (EXP-C18-01: d(e(X)) = X for all seven quasigroups.)
*Known:* Markovski, Gligoroski, Bakeva, Quasigroup string processing, Part 1
(1999).

## Theorem 2 (CLM-C18-02) — a difference propagates forward and only forward

If u and v differ exactly at position i, then e_l(u) and e_l(v) agree at
positions < i and differ at every position ≥ i.

*Proof.* Before i the computations coincide. At i, b_{i−1} is common and
a_i ≠ a′_i, so b_i ≠ b′_i (left cancellation). After i, the runs proceed over
the same inputs from different states, and right cancellation keeps them
different at every step (Lean `eT_ne_of_ne`). ∎

*Corollary (forward-only hashes fail the strict avalanche criterion).* In
QG(T, p, no reverse), changing a message byte at position i ≥ n − 8 cannot
change the output bytes at tail positions < i (apply Theorem 2 to each pass:
every pass sees inputs that agree before i). For the 17-byte messages of
EXP-C18-02, flipping a bit of key byte 15 changes at most the last two output
bytes, so 48 output bits have flip probability exactly 0 and the maximal bias
is 1/2. Observed for QG-LS p1, QG-LS p2 and QG-ARP p1 (max bias 0.5).

## Theorem 3 (CLM-C18-03) — the tail-information bound

(i) The last k outputs of an e-transformation are a bijective function of the
state b_{n−k−1} before them and the last k inputs: (b_{n−k}, …, b_{n−1}) =
e_{b_{n−k−1}}(a_{n−k}, …, a_{n−1}) (Lean `eT_append`, `eT_tail_factors`), and
e_{b} is injective (Theorem 1).

(ii) *Forward hashes.* For QG(T, p, no reverse) and messages of length n ≥ 8
the output is a function of the p bytes b^{(1)}_{n−8}, …, b^{(p)}_{n−8}
(the states of the passes at position n − 8) and of the last 7 message bytes.
Hence messages sharing their last 7 bytes receive at most 256^p distinct hash
values.

(iii) *Reverse-pass hashes.* For QG(T, p, reverse) the output is a function of
one byte and of the first 7 message bytes. Hence messages sharing their first
7 bytes receive at most **256** distinct 64-bit hash values, for every p.

*Proof.* (ii) By (i) with k = 7, the tail (b_{n−8}, …, b_{n−1}) of a pass is
determined by its first entry b_{n−8} and its last 7 inputs. The last 7
inputs of pass j are the last 7 outputs of pass j − 1, which (by the same
argument) are determined by b^{(j−1)}_{n−8} and the last 7 inputs of pass
j − 1; induction down to the message. (iii) The reverse pass reads R = rev(M′),
M′ the forward output; by (i) its last 8 outputs are determined by one state
byte and R_{n−7}, …, R_{n−1} = M′_6, …, M′_0. By Theorem 2 (or directly), the
first 7 entries of every forward pass depend only on the first 7 entries of
its input, hence M′_0, …, M′_6 depend only on M_0, …, M_6. ∎

*Corroboration.* EXP-C18-05: on 50 × 4096 keys sharing a 7-byte prefix the
reverse-pass hash takes exactly 256 values every time; the 1-pass forward hash
takes exactly 256 values on keys sharing the last 7 message bytes. This
explains the collisions of EXP-C18-03: 16 near-duplicate families of 2295 keys
sharing a 7-byte prefix give ≥ 16 · (2295 − 256) = 32,624 full collisions —
exactly the number observed for every reverse-pass variant (32,625 for
QG-LS p2+rev); the 2-pass forward hash (bound 256² on 10 · 255 keys per
family) shows the birthday-level count 723.

## Theorem 4 (CLM-C18-04) — the T-function obstruction

If x * y is a T-function on ℤ/2⁸ (bit j of x * y depends only on bits 0..j of x
and y) — e.g. any operation built from +, −, ×, ⊕ and constants: the affine
quasigroups a x + b y + c (a, b odd), x ⊕ y, and (x + 1) ⊕ y — then in every
QG hash (any passes, with or without reverse) bit j of every output byte
depends only on bits 0..j of the message bytes. Consequently flipping an input
bit at position r never changes an output bit at a position < r; flipping a
top bit (r = 7) changes at most 8 of the 64 output bits, and the maximal
avalanche bias is 1/2.

*Proof.* The T-function property says: x ≡ x′ and y ≡ y′ (mod 2^r) imply
x * y ≡ x′ * y′ (mod 2^r). Leaders, the length byte and padding are constants;
reversal permutes positions without mixing bits. Induction along every chain
shows that two messages congruent mod 2^r byte by byte produce outputs
congruent mod 2^r byte by byte. ∎ (EXP-C18-01: 0 violations; EXP-C18-02:
max bias 0.5 for AFF, ALP, XOR.) *Known in substance:* closure of T-functions
under composition (Klimov and Shamir, 2002).

## Theorem 5 (CLM-C18-05) — GF(2)-affine quasigroups give affine hashes

If x * y = A(x) ⊕ B(y) ⊕ c with A, B linear over GF(2) (e.g. x ⊕ y), every QG
hash is GF(2)-affine: H(M ⊕ Δ) = H(M) ⊕ L(Δ) for a fixed linear L. So every
avalanche cell is 0 or 1 and output differences do not depend on the key.

*Proof.* Compositions of affine maps are affine; reversal and constants
preserve affinity. ∎ (EXP-C18-01: one input difference → 1 distinct output
difference over 2000 keys; EXP-C18-02: mean bias 0.5 for QG-XOR and CRC32,
the latter being affine for the same reason.)

## Theorem 6 (CLM-C18-06) — the anchored quasigroup x + c(y) keeps additive differences

Let x * y = x + c(y) mod 256 (C06 Theorem 4 with c a permutation, c(0) = 1).
(i) Two runs over the same inputs from states b, b′ keep the constant
difference b′ − b at every position. (ii) One pass gives prefix sums
b_j = l + Σ_{i≤j} c(a_i), so the 1-pass tail hash is unchanged by any
permutation of the message bytes before the tail ("anagram blindness").

*Proof.* (i) (b′ + c(a)) − (b + c(a)) = b′ − b. (ii) Induction. ∎

*Consequences.* In QG-ARP p2+rev, flipping a message byte at position ≥ 8
leaves the first 8 forward outputs unchanged, so the reverse pass runs over the
same inputs from different states at the tail: all 8 output bytes change by the
same additive constant. The per-bit flip rates look ideal (max bias 0.043), but
the changes of corresponding bits are perfectly correlated (bit independence
1.0, EXP-C18-02). EXP-C18-01: 2000 of 2000 1-pass hashes unchanged under a
prefix permutation.

## Theorem 7 (CLM-C18-07) — the cascade keeps a full 8-byte state

In QC(T, d) the update of the state (s_1, …, s_d) by one input byte is a
bijection of Q^d. Hence two equal-length messages that differ in a prefix and
agree afterwards keep different states to the end, and the output (the whole
state) is not subject to the bound of Theorem 3: a family of messages sharing
a 7-byte prefix or suffix can receive up to 256^d values.

*Proof.* s_1 ↦ s_1 * x is a bijection (fixed x); given the new s_1, s_2 ↦
s_2 * s_1 is a bijection; and so on — a triangular composition of bijections.
Bijective updates never merge states. ∎ (This proves only that no
information-theoretic obstruction remains; the quality of QC-LS and QC-ISO is
an empirical result of EXP-C18-05, and QC-NIMINV shows a measurable bias.)
