# Cycle C11 — Written proofs (pattern-terminated universal codes)

Notation. For a binary pattern p of length k, T_p is the code whose codewords
are the binary words in which p occurs for the first time at the very end,
assigned to the integers 1, 2, 3, … in order of length and then
lexicographically. f_p(L) is the number of codewords of length L,
cum_p(L) = Σ_{l≤L} f_p(l), and the codeword of n has length
L_p(n) = min{L : cum_p(L) ≥ n}. c_p(x) = Σ_{j ∈ periods(p)} x^j is the
Guibas–Odlyzko autocorrelation polynomial (periods include 0), the same
object as the autocorrelation polynomial of cycle C01.

## Theorem 1 (CLM-C11-01) — T_p is a complete prefix code

(a) T_p is prefix-free (machine-checked: `Infinity.C11.prefix_free`,
`unique_parse_head`). (b) Σ_L f_p(L) 2^{−L} = 1. (c) The counts have generating
function F_p(x) = x^k / (x^k + (1 − 2x) c_p(x)). (d) T_11 has exactly the
codeword set of the Fibonacci (C1) code and T_{1^k} that of the order-k
generalisation "ends with 1^k and contains no other 1^k".

*Proof.* (a) If a codeword v were a proper prefix of a codeword w, then p (a
suffix of v) would occur in w ending before its end. (b) Σ_L f_p(L)2^{−L} is the
probability that a uniformly random infinite bit sequence contains p, which is
1. (c) Let A(x) count words avoiding p. Appending a letter to an avoiding word
gives either an avoiding word or a codeword: 1 + 2xA = A + F. Appending p to an
avoiding word w, the first occurrence of p in wp ends after a period j of p, so
wp is a codeword followed by the last j letters of p: x^k A = c_p F. Eliminating
A gives (c). (d) A word whose first "11" is at the end has the form u11 with u1
free of "11", i.e. a Zeckendorf digit string (least significant first, ending
in its top digit 1) followed by the terminating 1; similarly for 1^k. ∎

Consequence: the radius of convergence ρ_p of F_p is the smallest positive
root of D_p(x) = x^k + (1 − 2x) c_p(x) (Pringsheim), λ_p = 1/ρ_p is the growth
rate, and L_p(n)/log₂ n → 1/log₂ λ_p.

## Theorem 2 (CLM-C11-02) — the all-ones terminator has the largest growth rate

Among patterns of length k, 1^k and 0^k have the largest growth rate; every
pattern with a different autocorrelation has a strictly smaller one.

*Proof.* D_p(x) > 0 on (0, 1/2] (both terms are ≥ 0 and x^k > 0), so ρ_p > 1/2,
and D_p(1/2) = 2^{−k} for every p. c_{1^k} = 1 + x + … + x^{k−1} dominates every
c_p coefficientwise (all periods 0..k−1 are periods of 1^k), so for x > 1/2,
D_{1^k}(x) − D_p(x) = (1 − 2x)(c_{1^k}(x) − c_p(x)) ≤ 0, strictly if c_p ≠ c_{1^k}.
At x = ρ_p this gives D_{1^k}(ρ_p) ≤ 0 (< 0 in the strict case) while
D_{1^k}(1/2) > 0, so D_{1^k} has a root in (1/2, ρ_p]: ρ_{1^k} ≤ ρ_p, i.e.
λ_{1^k} ≥ λ_p, strictly when c_p ≠ c_{1^k}. Only 0^k and 1^k have every period. ∎

(Verified for all 2044 patterns of length 2..10, EXP-C11-02. This is in the
spirit of Guibas–Odlyzko's ordering of patterns by correlation.)

## Theorem 3 (CLM-C11-03) — unbordered terminators: the x/(1 − x) identity

If u is unbordered and |u| = k + 1, then F_u(x) = (x/(1 − x))·F_{1^k}(x), i.e.
f_u(L) = cum_{1^k}(L − 1). Hence λ_u = λ_{1^k} (the k-bonacci constant) and
cum_u(L)/cum_{1^k}(L) → 1/(λ − 1).

*Proof.* c_{1^k} = (1 − x^k)/(1 − x), so D_{1^k} = (1 − 2x + x^{k+1})/(1 − x) and
F_{1^k} = x^k(1 − x)/(1 − 2x + x^{k+1}). For unbordered u, c_u = 1 and
F_u = x^{k+1}/(1 − 2x + x^{k+1}). Divide. For the ratio, the k-bonacci polynomial
is Pisot, so cum_{1^k}(L) = Cλ^L(1 + o(1)), and cum_u(L) = Σ_{l≤L} cum_{1^k}(l−1)
= Cλ^L/(λ − 1)(1 + o(1)). ∎

(Verified with exact integers for every unbordered pattern of length 3..9 up
to length 200, EXP-C11-06.)

## Corollary 4 (CLM-C11-04) — T_011 versus the Fibonacci code

cum_11(L) = F_{L+1} − 1 and cum_011(L) = F_{L+2} − L − 1. For n ≥ 5, T_011 is
never longer than the Fibonacci code; if the Fibonacci codeword of n has length
L + 1 (F_{L+1} ≤ n ≤ F_{L+2} − 1), the T_011 codeword is one bit shorter when
n ≤ F_{L+2} − L − 1 and of equal length for the last L values. T_011 is longer
only for n ∈ {1, 2, 4}.

*Proof.* f_11(L) = F_{L−1} gives cum_11; Theorem 3 with k = 2 gives
f_011(l) = F_l − 1 and cum_011(L) = Σ_{l=1}^{L} F_l − L = F_{L+2} − L − 1. For
F_{L+1} ≤ n ≤ F_{L+2} − 1: n > F_{L+1} − L = cum_011(L−1), so L_011(n) ≥ L;
L_011(n) = L iff n ≤ cum_011(L); and n ≤ F_{L+2} − 1 ≤ cum_011(L+1) =
F_{L+3} − L − 2 iff F_{L+1} ≥ L + 1, true for L ≥ 4. The cases n ≤ 4 are
checked directly. ∎ (Exhaustively confirmed for n ≤ 2·10⁶ and block-wise up to
L = 90.)

## Proposition 5 (CLM-C11-07) — the average gain oscillates

Let k ≥ 2, λ the k-bonacci constant, O = T_{1^k}, U = T_u with u unbordered of
length k + 1, and G(N) = (1/N)Σ_{n≤N}(L_O(n) − L_U(n)). Then
liminf G(N) = (2 − λ)/(λ − 1)² and limsup G(N) = λ(2 − λ)/(λ − 1); for k = 2
both equal 1, for k = 3 they are 0.2282 and 0.3522.

*Proof.* Put r = 1/(λ − 1); 1 < r ≤ λ (equality iff k = 2). By Theorem 3,
cum_U(L) = r·cum_O(L)(1 + o(1)). On the level I_L = (cum_O(L−1), cum_O(L)] of O
(length L), U has length L − 1 exactly on S_L = (cum_O(L−1), cum_U(L−1)] (for
k ≥ 3; since r < λ, cum_U(L−2) < cum_O(L−1)) and length L elsewhere (since
r > 1), so the gain is 1 on S_L and 0 on I_L∖S_L, with |S_L| ~ (r − 1)cum_O(L−1).
G increases along S_L and decreases along I_L∖S_L, so its extreme values occur
at N = cum_O(L) and N = cum_U(L−1). Summing the geometric series,
G(cum_O(L)) → (r − 1)/(λ − 1) and G(cum_U(L−1)) → (r − 1)λ/(r(λ − 1)); with
r − 1 = (2 − λ)/(λ − 1) these are the stated constants. For k = 2 the level is
saved except for O(L) values (Corollary 4), so G → 1. ∎ (Agreement to 6 digits
for k = 2..6 at L = 100, 200, 400, EXP-C11-08.)

## Corollary 6 (CLM-C11-09) — T_011 versus the Fraenkel–Klein code C3

Fraenkel and Klein (1996) improve C1 by the code C3: delete the final 1 of every
C1 codeword, take each length block twice and prefix the copies with 10 and 11
(101, 111, 1001, 1101, 10001, …). C3 is uniquely decipherable and complete but
not prefix-free (its decoder looks one bit into the next codeword), and it has
2F_{r−2} codewords of length r ≥ 3 (their Proposition 5), so
cum_C3(L) = 2F_L − 2. Then

(a) C3 is never longer than C1 except at n = 1;
(b) T_011 is never longer than C3 except at n ∈ {2, 4, 8};
(c) cum_011(L)/cum_C3(L) → φ²/2 ≈ 1.309 and cum_C3(L)/cum_C1(L) → 2/φ ≈ 1.236.

*Proof.* As L_X(n) = min{L : cum_X(L) ≥ n}, the code X is longer than Y at n
exactly when cum_Y(L) ≥ n > cum_X(L) for some L. (a) cum_C3(L) − cum_C1(L) =
2F_L − 2 − F_{L+1} + 1 = F_{L−2} − 1, which is ≥ 0 for L ≥ 3; for L ≤ 2 the only
deficit is cum_C3(2) = 0 < 1 = cum_C1(2), i.e. n = 1. (b) Using
F_{L+2} − 2F_L = F_{L−1}, cum_011(L) − cum_C3(L) = F_{L−1} − (L − 1). This is 0 for
L = 1, 2, nonnegative for L ≥ 6 (F_m ≥ m for m ≥ 5) and equal to −1 for
L = 3, 4, 5, where (cum_011(L), cum_C3(L)] = (1, 2], (3, 4], (7, 8]. (c) F_{L+2}/F_L
→ φ² and F_L/F_{L+1} → 1/φ. ∎ (Exhaustively confirmed for n ≤ 2·10⁶ and the count
inequalities for L < 300, EXP-C11-09.)

By Corollary 4 the average of L_C1 − L_011 tends to 1; C3 recovers only part of
that bit: the measured averages of L_C1 − L_C3 over n ≤ 2⁴⁰, 2⁸⁰, 2¹²⁰ are 0.462,
0.400 and 0.481 (they oscillate, as in Proposition 5). On sources concentrated
on small n, the three exceptions of (b) let C3 beat T_011 (EXP-C11-09).

## Refutations recorded in this cycle

* H-C11-2 (1^k is the best length-k terminator beyond small n): false at
  practical sizes for k ≥ 4 (unbordered patterns are shorter at sampled n up to
  1.3·10¹⁹ for k = 6), though true asymptotically (Theorem 2).
* The first prediction of the average gain, log_λ(1/(λ − 1)) (EXP-C11-06), and
  the corrected claim that the average converges (EXP-C11-07): both false for
  k ≥ 3; Proposition 5 is the correct statement.
