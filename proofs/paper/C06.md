# Cycle C06 — Written proofs (successor-anchored magmas)

Setting. A *successor-anchored magma* of size N is a binary operation ⋆ on
ℤ/N = {0, …, N−1} with x ⋆ 0 = x + 1 for every x (the anchor). (Laver's
convention {1, …, N} with p ⋆ 1 = p + 1, N ⋆ 1 = 1 is the relabelling
p ↦ p − 1.)

## Theorem 1 (CLM-C06-02) — anchored associativity gives exactly one model, for every N

If ⋆ is associative and anchored, then x ⋆ y = x + y + 1 (mod N); conversely
this operation is associative and anchored. So the spectrum is every N ≥ 1
with exactly one model, a cyclic group (identity element −1).

*Proof.* Associativity with z = 0 gives x ⋆ (y ⋆ 0) = (x ⋆ y) ⋆ 0, i.e.
x ⋆ (y + 1) = (x ⋆ y) + 1. Induction on y from x ⋆ 0 = x + 1 gives
x ⋆ y = x + 1 + y. Conversely (x ⋆ y) ⋆ z = x + y + z + 2 = x ⋆ (y ⋆ z), and
x ⋆ 0 = x + 1. The map x ↦ x + 1 is an isomorphism onto (ℤ/N, +). ∎

## Theorem 2 (CLM-C06-03) — anchored right-distributivity gives exactly one model, for every N

If (x ⋆ y) ⋆ z = (x ⋆ z) ⋆ (y ⋆ z) and x ⋆ 0 = x + 1, then x ⋆ y = x + 1 for
all x, y; conversely this operation satisfies both. Spectrum: every N, one
model.

*Proof.* Put z = 0: (x ⋆ y) + 1 = (x + 1) ⋆ (y + 1). Hence
f(x, y) = x ⋆ y satisfies f(x + 1, y + 1) = f(x, y) + 1, so
f(x, y) = x + g(y − x) with g(d) = 0 ⋆ d. The anchor gives
x + g(−x) = x + 1 for every x, so g ≡ 1 and x ⋆ y = x + 1. Conversely
(x ⋆ y) ⋆ z = x + 2 = (x + 1) ⋆ (y + 1) = (x ⋆ z) ⋆ (y ⋆ z). ∎

## Theorem 3 (CLM-C06-01, rediscovery) — left-distributivity: the Laver tables

For N = 2^n there is exactly one anchored left-distributive magma (the Laver
table A_n); for other N there is none (Laver 1992; Drápal). *Our evidence:*
Laver's recursion produces left-distributive tables exactly for N = 1, 2, 4,
…, 64 among N ≤ 64, verified exhaustively up to N = 256 (EXP-C06-01); an
independent SAT enumeration that does not use the recursion confirms
existence/uniqueness for small N (EXP-C06-02). We do not re-prove the general
theorem.

*Why left- and not right-distributivity is special.* In Theorems 1–2 the
anchor sits in the position that the law propagates *along*, so it pins the
whole table. Left-distributivity propagates the anchor through
p ⋆ (q + 1) = (p ⋆ q) ⋆ (p + 1), which refers to *other rows*; consistency
of this recursion is a genuine arithmetic constraint on N.

## Theorem 4 (CLM-C06-05) — anchored right-permutable magmas: x ⋆ y = x + c(y), N^(N−1) models

If (x ⋆ y) ⋆ z = (x ⋆ z) ⋆ y and x ⋆ 0 = x + 1, then x ⋆ y = x + c(y) for a
function c : ℤ/N → ℤ/N with c(0) = 1; conversely every such operation is
right-permutable and anchored. Hence there are exactly N^(N−1) anchored
right-permutable magmas of size N.

*Proof.* The law says that the right translations R_z(x) = x ⋆ z commute
pairwise. R_0 is the successor s(x) = x + 1, so every R_y commutes with s:
R_y(x + 1) = R_y(x) + 1, whence R_y(x) = x + R_y(0). Put c(y) = 0 ⋆ y; the
anchor gives c(0) = 1. Conversely (x ⋆ y) ⋆ z = x + c(y) + c(z) is symmetric
in y, z. The values c(1), …, c(N − 1) are free: N^(N−1) tables. ∎
(EXP-C06-02 counts 1, 2, 9, 64, 625 for N = 1..5, as predicted.)

## Theorem 5 (CLM-C06-06) — an "odd" law: (x ⋆ y) ⋆ z = x ⋆ ((y ⋆ z) ⋆ z)

An anchored magma of size N satisfying (x ⋆ y) ⋆ z = x ⋆ ((y ⋆ z) ⋆ z) exists
iff N is odd, and then it is unique: x ⋆ y = x + 1 + h·y with h = (N + 1)/2
(the inverse of 2 modulo N).

*Proof.* Put z = 0 and use the anchor twice: (x ⋆ y) + 1 = x ⋆ (y + 2). Hence
x ⋆ (y + 2k) = (x ⋆ y) + k for all k ≥ 0. If N is even, k = N/2 gives
x ⋆ y = x ⋆ y + N/2 (mod N), impossible for N ≥ 2. If N is odd, every y is
2k mod N for k = h·y, so x ⋆ y = x ⋆ 0 + h·y = x + 1 + h·y. Conversely, with
2h ≡ 1: (x ⋆ y) ⋆ z = x + h y + h z + 2, (y ⋆ z) ⋆ z = y + z + 2, and
x ⋆ (y + z + 2) = x + 1 + h y + h z + 2h = x + h y + h z + 2. ∎

## Theorem 6 (CLM-C06-07) — a "golden" law: (x ⋆ y) ⋆ z = x ⋆ (y ⋆ (z ⋆ z))

The anchored magmas of size N satisfying (x ⋆ y) ⋆ z = x ⋆ (y ⋆ (z ⋆ z)) are
exactly the tables x ⋆ y = x + 1 + a·y (mod N) with a² + a ≡ 1 (mod N), and
distinct roots a give distinct tables. Consequently the spectrum is the set
of N = 5^e·m with e ∈ {0, 1} and every prime factor of m congruent to ±1
modulo 5 (1, 5, 11, 19, 29, 31, 41, 55, 59, 61, …), and the number of models
is 2^ω(m), ω(m) the number of distinct prime factors of m.

*Proof.* (i) *Every model is a "translation table".* Put z = 0: since
0 ⋆ 0 = 1, x ⋆ (y ⋆ 1) = (x ⋆ y) + 1. With σ(y) = y ⋆ 1 this reads
x ⋆ σ(y) = (x ⋆ y) + 1, so x ⋆ σ^k(0) = x + 1 + k for all k ≥ 0. For x = 0 the
values 1 + k (k = 0, …, N − 1) are distinct, so the elements σ^k(0) are
distinct and exhaust ℤ/N; and σ^N(0) = σ^j(0) with j < N forces
N + 1 ≡ j + 1, i.e. j = 0. So κ(σ^k(0)) := k mod N is a well-defined
bijection ℤ/N → ℤ/N with κ(0) = 0 and x ⋆ y = x + 1 + κ(y).
(ii) *The law for κ.* Substituting, (x ⋆ y) ⋆ z = x + 2 + κ(y) + κ(z) and
x ⋆ (y ⋆ (z ⋆ z)) = x + 1 + κ(y + 1 + κ(z + 1 + κ(z))), so the law is
equivalent to
  κ(y + 1 + κ(z + 1 + κ(z))) = κ(y) + κ(z) + 1   for all y, z.   (∗)
(iii) *κ is linear.* At z = 0, (∗) gives κ(y + c) = κ(y) + 1 with
c = 1 + κ(1), hence κ(y + jc) = κ(y) + j. If d = gcd(c, N) > 1, then j = N/d
gives jc ≡ 0 and N/d ≡ 0 (mod N), impossible; so c is a unit mod N and
κ(y) = a·y with a = c^(−1).
(iv) *The equation for a.* From c = 1 + κ(1) = 1 + a and ac = 1 we get
a² + a ≡ 1. Conversely, for κ(y) = a·y, (∗) reads
a + a² − 1 + (a³ + a² − a)·z ≡ 0 for all z, and both coefficients vanish
when a² + a ≡ 1 (the second is a(a² + a − 1)). So the models correspond
exactly to the roots; distinct roots give distinct entries 0 ⋆ 1 = 1 + a.
(v) *Counting roots.* a² + a is always even, so there is no root modulo 2
and N is odd. For odd N, a² + a ≡ 1 ⟺ (2a + 1)² ≡ 5. Modulo 5 the only root
is a = 2; modulo 25 there is none (5 would have even 5-adic valuation). For
an odd prime p ≠ 5 there are two roots modulo p iff 5 is a square mod p,
i.e. p ≡ ±1 (mod 5) by quadratic reciprocity, and each lifts uniquely to
p^k by Hensel's lemma (the derivative 2a + 1 is a unit). The Chinese
remainder theorem multiplies the counts. ∎

## Theorem 7 (CLM-C06-08) — anchored left-permutable magmas are commutative monoids in disguise

Let M = ℤ/N. The maps

  (M, ⋆) ↦ (M, ·),  a · b := (a − 1) ⋆ b,      and      (M, ·) ↦ (M, ⋆),  x ⋆ y := (x + 1) · y

are mutually inverse bijections between anchored magmas satisfying the
left-permutable law x ⋆ (y ⋆ z) = y ⋆ (x ⋆ z) and commutative monoid
structures on M with identity element 0. Hence the number of anchored
left-permutable magmas of size N is the number of labelled commutative monoids
of order N with a fixed identity (OEIS A058156: 1, 2, 9, 94, 1486, …).

*Proof.* Let (M, ⋆) be anchored and left-permutable and put f_m := L_{m−1},
where L_x(z) = x ⋆ z. The law says that the f_m commute pairwise, and the
anchor says f_m(0) = m.
(a) *The centraliser of F = {f_m} is F.* If g : M → M commutes with every f_m,
then g(m) = g(f_m(0)) = f_m(g(0)). Put k = g(0). Since f_k and f_m commute,
f_m(k) = f_m(f_k(0)) = f_k(f_m(0)) = f_k(m). So g(m) = f_k(m) for all m: g = f_k.
(b) For any a, b the composite f_a ∘ f_b commutes with every f_c, hence equals
f_k with k = f_a(f_b(0)) = f_a(b); and the identity map commutes with every
f_c, hence equals f_0.
(c) Define a · b := f_a(b) = (a − 1) ⋆ b. By (b), f_{a·b} = f_a ∘ f_b, so
(a · b) · c = f_a(f_b(c)) = a · (b · c); a · b = f_a(f_b(0)) = f_b(f_a(0))
= b · a; 0 · b = f_0(b) = b. So (M, ·) is a commutative monoid with identity 0.
(d) Conversely, if (M, ·) is a commutative monoid with identity 0, then
x ⋆ y := (x + 1) · y satisfies x ⋆ 0 = x + 1 and
x ⋆ (y ⋆ z) = (x + 1)(y + 1) z = y ⋆ (x ⋆ z). The two constructions are
inverse to each other by definition: a ↦ a − 1 ↦ a. ∎

*Remark.* The successor is used only as a labelling: what the proof really
shows is that a commuting family of maps that reaches every point from 0
exactly once is the regular representation of a commutative monoid.

## Theorem 8 (CLM-C06-12) — anchored spectra are closed under coprime products

For every set of laws (identities) E: if E has an anchored model of size N and
one of size M with gcd(N, M) = 1, then it has an anchored model of size NM.
Consequently no set of laws has exactly the primes (or any infinite set of
primes without their products) as its anchored spectrum, and every spectrum
is determined by which products of prime powers it contains.

*Proof.* Let (ℤ/N, ⋆₁) and (ℤ/M, ⋆₂) be anchored models. The product magma on
ℤ/N × ℤ/M, (x₁, x₂) ⋆ (y₁, y₂) = (x₁ ⋆₁ y₁, x₂ ⋆₂ y₂), satisfies every identity
that holds in both factors (identities are evaluated componentwise). By the
Chinese remainder theorem φ : ℤ/NM → ℤ/N × ℤ/M, x ↦ (x mod N, x mod M), is a
bijection with φ(0) = (0, 0) and φ(x + 1) = φ(x) + (1, 1). Transport the
product operation along φ: x ⋆ y := φ⁻¹(φ(x) ⋆ φ(y)). This magma satisfies E,
and x ⋆ 0 = φ⁻¹((x₁ + 1, x₂ + 1)) = φ⁻¹(φ(x + 1)) = x + 1. ∎

*Remark.* The examples so far are also closed under divisors (powers of 2,
odd numbers, A089270, {1, 2}, {1, 3}). For affine models this is automatic
(reduce a modulo d), and for Laver tables it is the classical projection
A_n → A_{n−1}; whether *every* anchored spectrum is divisor-closed is open
(hypothesis H-C13-1 of the next cycle).
