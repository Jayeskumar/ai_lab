# Cycle C17 — Written proofs (deciding laws of finite magmas)

A finite magma is a Cayley table T on M = {0, …, n − 1}. Cost is measured in
*probes* (table look-ups). Code: `systems/law_testing.py`.

---

## Theorem 1 (CLM-C17-01) — Light's associativity test

Let S ⊆ M generate (M, ⋆) as a magma. Then ⋆ is associative iff
(x ⋆ s) ⋆ y = x ⋆ (s ⋆ y) for all x, y ∈ M and s ∈ S. The test costs
2n + 2n² probes per generator.

*Proof.* Let A = {a ∈ M : (x ⋆ a) ⋆ y = x ⋆ (a ⋆ y) for all x, y}. By
hypothesis S ⊆ A. If a, b ∈ A, then for all x, y:
(x ⋆ (a ⋆ b)) ⋆ y = ((x ⋆ a) ⋆ b) ⋆ y      [a ∈ A, with y := b]
                 = (x ⋆ a) ⋆ (b ⋆ y)      [b ∈ A, with x := x ⋆ a]
                 = x ⋆ (a ⋆ (b ⋆ y))      [a ∈ A, with y := b ⋆ y]
                 = x ⋆ ((a ⋆ b) ⋆ y)      [b ∈ A, with x := a].
So a ⋆ b ∈ A; A is a submagma containing S, hence A = M, which is
associativity. The converse is trivial. ∎ (F. W. Light's test, as presented in
A. H. Clifford and G. B. Preston, *The Algebraic Theory of Semigroups*, Vol. 1,
§1.2.)

## Corollary 2 (CLM-C17-02) — anchored magmas: one generator, and an O(n²) criterion

If x ⋆ 0 = x + 1 (mod n) for all x, then {0} generates (M, ⋆) (0, 0 ⋆ 0 = 1,
1 ⋆ 0 = 2, …), so Light's test with S = {0} decides associativity with
2n + 2n² probes. Even more directly, ⋆ is associative iff
x ⋆ (y + 1) = (x ⋆ y) + 1 for all x, y (2n² probes as implemented; comparing
the table with x + y + 1 directly needs only n², as the Skeptic remarks).

*Proof.* The identity is the instance z = 0 of associativity, so it is
necessary. Conversely, it gives x ⋆ y = x + y + 1 by induction on y (C06
Theorem 1, Lean `anchored_assoc_unique`), which is associative. ∎

## Theorem 3 (CLM-C17-03) — the Rajagopalan–Schulman test is one-sided

If ⋆ is associative the randomised test always accepts; if not, each round
rejects with probability at least 1/8 (Rajagopalan and Schulman, SIAM J.
Comput. 29 (2000) 1155–1168). Each round costs O(n²) probes: with indicator
vectors u, v, w of random subsets over GF(2), the formal products
(u ⋆ v) ⋆ w and u ⋆ (v ⋆ w) in the magma algebra are computed by four
"bincount" passes (u ⋆ v, then (u ⋆ v) ⋆ w, v ⋆ w, then u ⋆ (v ⋆ w)), each
counted as n² probes, 4n² per round.

*Proof of one-sidedness.* Extend ⋆ bilinearly to the algebra GF(2)[M]; if ⋆
is associative on M, it is associative on the algebra, so both products agree.
The detection bound is the cited theorem (we do not re-prove it; EXP-C17-01
measures the empirical behaviour). ∎

## Observation 4 (CLM-C17-05) — the anchor instance of left-distributivity

For anchored magmas of size 2 ≤ N ≤ 10, the single identity
x ⋆ (y + 1) = (x ⋆ y) ⋆ (x + 1) (all x, y mod N, i.e. the instance z = 0 of
left-distributivity including the wrap-around y = N − 1) has solutions exactly
for N = 2, 4, 8, each unique and left-distributive (EXP-C17-02). If this
holds for all N, left-distributivity of an anchored table can be decided with
O(N²) probes. (Without the wrap-around instance, Laver's recursion has a
unique solution for every N, left-distributive only for powers of 2.)

*Uniqueness for every N (added after the Skeptic's review,
reviews/skeptic_C07_C17_C20.md A.5; checked by the Director).* Suppose
x ⋆ 0 = x + 1 (mod N) and x ⋆ (y + 1) = (x ⋆ y) ⋆ (x + 1) for y = 0, …, N − 2.
Row N − 1: (N − 1) ⋆ (y + 1) = ((N − 1) ⋆ y) ⋆ 0 = (N − 1) ⋆ y + 1 and
(N − 1) ⋆ 0 = 0, so (N − 1) ⋆ y = y for all y. For x < N − 1, by downward
induction on x, every entry of row x exceeds x and is determined: x ⋆ 0 =
x + 1 > x; if x ⋆ y = v > x, then x ⋆ (y + 1) = v ⋆ (x + 1) with x + 1 ≤ N − 1
(no wrap-around), which is x + 1 when v = N − 1 and otherwise an entry of the
already determined row v ∈ (x, N − 1), hence > v > x. So the instances
y ≤ N − 2 force at most one table, for every N; it is a model of the full
instance iff the wrap-around equations x + 1 = (x ⋆ (N − 1)) ⋆ (x + 1) hold.
This is exactly Laver's recursion, so at N = 2ⁿ the forced table is the Laver
table A_n, which is left-distributive and therefore satisfies the instance. ∎

What remains open is the converse for all N: that the wrap-around fails at
every N that is not a power of 2. It holds for every N ≤ 4096, both in the
lab's own EXP-C17-03 (pure Python, 30 minutes) and in the Skeptic's independent
C program.


## Theorem 5 (CLM-C17-08) — the full anchor instance has a model iff N is a power of 2

*(Batch 1.1. The argument is the Historian's — reviews/historian_C11_C20.md,
"The CLM-C17-05 question", item 4 — completed and machine-checked by the
Skeptic, reviews/skeptic_batch1.1.md §1.2; Lean:
proofs/lean/Infinity/C17_RowPeriod.lean, `full_instance_iff_pow_two`.)*

For every N ≥ 1, an anchored table on {0, …, N−1} satisfies
x ⋆ (y + 1) = (x ⋆ y) ⋆ (x + 1) for all x, y (wrap-around included) iff N is a
power of 2. The proof uses one published fact: Laver's theorem that the Laver
table A_n is left-distributive (so it satisfies the full instance), needed only
at the order 2^(v₂(N)+1).

Let F_N be the table forced by the instances y ≤ N − 2 (Observation 4). Row
N − 1 is the identity and every entry of a row x ≤ N − 2 exceeds x.

*Lemma A (rows of F_N are periodic).* For x ≤ N − 2, while the entries of row
x stay below N − 1 they strictly increase; row x reaches N − 1 at a first
column y₀ ≤ N − 2 − x, and then x ⋆ (y₀ + 1) = (N − 1) ⋆ (x + 1) = x + 1 =
x ⋆ 0, so the row repeats with period π(x) = y₀ + 1, and N − 1 occurs only at
the columns ≡ y₀ (mod π(x)). Hence x ⋆ (N − 1) = N − 1 iff π(x) divides N.

*Lemma B (the wrap-around equation).* For x ≤ N − 2, x + 1 = (x ⋆ (N−1)) ⋆ (x+1)
iff x ⋆ (N − 1) = N − 1: if v = x ⋆ (N − 1) ≤ N − 2 then v > x and
v ⋆ (x + 1) > v ≥ x + 1. (This is Aguilera–Iannella's Prop. 2.5.) So F_N
satisfies the full instance iff every period π(x) divides N.

*Input (Laver).* For B = 2^(k+1), F_B = A_(k+1) satisfies the full instance, so
every period π_B(u) divides B and is smaller than B; hence it divides m = 2^k,
and (P) u ⋆_B y = u ⋆_B (y mod m) for u ≤ B − 2.

*Proof for N not a power of 2.* Write N = m·r with m = 2^k, r ≥ 3 odd, B = 2m
and s = N − B (so m divides s). (i) For s ≤ x ≤ N − 2 and all y,
x ⋆_N y = s + (x − s) ⋆_B (y mod m) — by descending induction on x and
ascending induction on y, using (P), m | s, and, when an entry equals N − 1,
that the top rows of both tables are identities. (ii) Row s − 1 of F_N is
y ↦ s + (y mod B), so its period is B, which does not divide N because
v₂(N) = k. By Lemmas A and B the wrap-around equation fails at x = s − 1, so F_N
— the only candidate — is not a model. For N = 2^n the Laver table is a model
(Laver) and the only one (uniqueness). ∎

The Lean proof takes Laver's theorem as an explicit hypothesis ("for every j
some anchored table of order 2^j satisfies the full instance") and proves the
equivalence for every N from it, with the standard axioms only. Numerically,
Lemmas A, B and the equivalence hold for every N ≤ 1000 and N = 1024, and (i),
(ii) for every non-power of 2 up to 4096 (the reviewers' scripts).
