# Cycle C17 — Written proofs (deciding laws of finite magmas)

A finite magma is a Cayley table T on M = {0, …, n − 1}. Cost is measured in
*probes* (table look-ups). Code: `systems/law_testing.py`.

---

## Theorem 1 (CLM-C17-01) — Light's associativity test

Let S ⊆ M generate (M, ⋆) as a magma. Then ⋆ is associative iff
(x ⋆ s) ⋆ y = x ⋆ (s ⋆ y) for all x, y ∈ M and s ∈ S. The test costs
2n + 2n² probes per generator.

*Proof.* Let A = {a ∈ M : (x ⋆ a) ⋆ y = x ⋆ (a ⋆ y) for all x, y}. By
hypothesis S ⊆ A. If a, b ∈ A, then for all x, y:
(x ⋆ (a ⋆ b)) ⋆ y = ((x ⋆ a) ⋆ b) ⋆ y      [a ∈ A, with y := b]
                 = (x ⋆ a) ⋆ (b ⋆ y)      [b ∈ A, with x := x ⋆ a]
                 = x ⋆ (a ⋆ (b ⋆ y))      [a ∈ A, with y := b ⋆ y]
                 = x ⋆ ((a ⋆ b) ⋆ y)      [b ∈ A, with x := a].
So a ⋆ b ∈ A; A is a submagma containing S, hence A = M, which is
associativity. The converse is trivial. ∎ (F. W. Light's test, as presented in
A. H. Clifford and G. B. Preston, *The Algebraic Theory of Semigroups*, Vol. 1,
§1.2.)

## Corollary 2 (CLM-C17-02) — anchored magmas: one generator, and an O(n²) criterion

If x ⋆ 0 = x + 1 (mod n) for all x, then {0} generates (M, ⋆) (0, 0 ⋆ 0 = 1,
1 ⋆ 0 = 2, …), so Light's test with S = {0} decides associativity with
2n + 2n² probes. Even more directly, ⋆ is associative iff
x ⋆ (y + 1) = (x ⋆ y) + 1 for all x, y (2n² probes).

*Proof.* The identity is the instance z = 0 of associativity, so it is
necessary. Conversely, it gives x ⋆ y = x + y + 1 by induction on y (C06
Theorem 1, Lean `anchored_assoc_unique`), which is associative. ∎

## Theorem 3 (CLM-C17-03) — the Rajagopalan–Schulman test is one-sided

If ⋆ is associative the randomised test always accepts; if not, each round
rejects with probability at least 1/8 (Rajagopalan and Schulman, SIAM J.
Comput. 29 (2000) 1155–1168). Each round costs O(n²) probes: with indicator
vectors u, v, w of random subsets over GF(2), the formal products
(u ⋆ v) ⋆ w and u ⋆ (v ⋆ w) in the magma algebra are computed by two
"bincount" passes of n² probes each.

*Proof of one-sidedness.* Extend ⋆ bilinearly to the algebra GF(2)[M]; if ⋆
is associative on M, it is associative on the algebra, so both products agree.
The detection bound is the cited theorem (we do not re-prove it; EXP-C17-01
measures the empirical behaviour). ∎

## Observation 4 (CLM-C17-05) — the anchor instance of left-distributivity

For anchored magmas of size 2 ≤ N ≤ 10, the single identity
x ⋆ (y + 1) = (x ⋆ y) ⋆ (x + 1) (all x, y mod N, i.e. the instance z = 0 of
left-distributivity including the wrap-around y = N − 1) has solutions exactly
for N = 2, 4, 8, each unique and left-distributive (EXP-C17-02). If this
holds for all N, left-distributivity of an anchored table can be decided with
O(N²) probes. (Without the wrap-around instance, Laver's recursion has a
unique solution for every N, left-distributive only for powers of 2.)
