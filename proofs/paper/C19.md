# Cycle C19 — Written proofs (the longest Zeckendorf game)

**Setting.** Chips lie on levels k = 0, 1, 2, …; a chip on level k is worth
F_{k+1} in the indexing F_1 = 1, F_2 = 2, F_{i+1} = F_i + F_{i−1} (so level k
carries 1, 2, 3, 5, 8, … and the paper index of level k is i = k + 1). The
game of Baird-Smith, Epstein, Flynt and Miller starts with n chips on level 0
and allows

* C1: F_1 ∧ F_1 → F_2; C_i (i ≥ 2): F_{i−1} ∧ F_i → F_{i+1} (*combines*);
* S2: F_2 ∧ F_2 → F_1 ∧ F_3; S_i (i ≥ 3): F_i ∧ F_i → F_{i−2} ∧ F_{i+1} (*splits*).

Every game ends at the Zeckendorf representation Σ_i δ_i F_i of n. MC_i and
MS_i count the moves of each kind, Z(n) = Σ δ_i, IZ(n) = Σ i δ_i,
a_i = F_{i+2} − i − 2 and B(n) = Σ_i a_i δ_i (the bound of Cusenza et al.,
Fib. Quart. 60 (2022), Thm 1.3). L(n) denotes the length of a longest game and
D(n) = B(n) − L(n).

Results used from the literature (not re-proved here): **[C, Thm 1.2]** the
strategy "make a split or combine-1 move whenever possible (in any order),
otherwise the combine C_i with the smallest i" produces a longest game, from any
starting position (Cusenza et al. 2022, Lemma 2.3 and Thm 1.2; independently
confirmed for n ≤ 150 by exhaustive search, EXP-C19-01).

## Theorem 1 (CLM-C19-01) — an exact length identity

For every game G on n,

  |G| = B(n) − Σ_{i ≥ 2} (i − 1) · MC_i(G).

Consequently L(n) = B(n) − D(n) with D(n) = min_G Σ_{i≥2} (i − 1) MC_i(G): a
game is longest exactly when it minimises the weighted number of consecutive
combines, and L(n) ≤ B(n) with equality iff some game uses no move C_i, i ≥ 2.

*Proof.* Let Ψ(c) = Σ_k c_k a_{k+1} for a configuration c (c_k chips on level
k). Then Ψ(n·[F_1]) = n a_1 = 0 since a_1 = F_3 − 3 = 0, and Ψ(Zeckendorf(n)) =
B(n). We compute the change of Ψ under each move, using
F_{m+1} = F_m + F_{m−1} (m ≥ 2):

* C1: a_2 − 2a_1 = (5 − 4) − 0 = 1;
* S2: a_1 + a_3 − 2a_2 = 0 + 3 − 2 = 1;
* S_i, i ≥ 3: a_{i−2} + a_{i+1} − 2a_i
  = (F_i + F_{i+3} − 2F_{i+2}) − ((i − 2) + (i + 1) − 2i) − (2 + 2 − 4)
  = (F_i + F_{i+1} − F_{i+2}) + 1 = 1;
* C_i, i ≥ 2: a_{i+1} − a_i − a_{i−1}
  = (F_{i+3} − F_{i+2} − F_{i+1}) − ((i + 1) − i − (i − 1)) − (2 − 2 − 2) = i.

Summing over the moves of G: B(n) − 0 = MC_1 + Σ MS_i + Σ_{i≥2} i·MC_i
= |G| + Σ_{i≥2} (i − 1)MC_i. ∎

*Remark.* The identity is implicit in the linear-algebra proof of [C, Thm 1.3]
and appears as an inequality step ("subtract the excess MC_2 + 2MC_3 + …") in
Cheigh et al. (2025); the potential Ψ gives it in one line, for every game.
Checked on all greedy games n < 1500 and 1500 random games (EXP-C19-02).

## Theorem 2 (CLM-C19-02) — the split phase ends at the lazy representation

Call C1 and the splits S_i *split moves*. From n chips on level 0, every
maximal sequence of split moves has the same length and ends at the **lazy
Fibonacci representation** of n: the unique representation n = Σ_{k∈K} F_{k+1}
with distinct levels K and no two consecutive empty levels below max K.

*Proof.* (a) *Abelian property.* A split move at level k needs c_k ≥ 2 and only
lowers c_k; split moves at different levels therefore stay legal after each
other and commute. Since every sequence of moves is finite (the game
terminates), the diamond lemma gives a unique stable end point stab(c) (all
levels ≤ 1) and a common length for all maximal split sequences from c, and
stab(c + e_0) = stab(stab(c) + e_0) (a legal sequence from c is legal from
c + e_0; continue from there).

(b) *A carry lemma.* For p ≥ 1 let Y_p = 2e_0 + e_1 + … + e_{p−1} and
Z_p = Σ_{0≤k≤p, k≡p (mod 2)} e_k (both of value F_{p+2} − 1). Then Y_p →* Z_p by
split moves at levels < p. For p = 1: 2e_0 → e_1 (C1). For p = 2:
2e_0 + e_1 → 2e_1 → e_0 + e_2. For p ≥ 3, Y_p = Y_{p−1} + e_{p−1}; the moves
Y_{p−1} →* Z_{p−1} (induction) are legal from Y_p and lead to
Z_{p−1} + e_{p−1} = 2e_{p−1} + Σ_{k≤p−3, k≡p−1} e_k. Now fire levels
ℓ = p − 1, p − 3, …: each fired level ℓ ≥ 2 holds exactly two chips, sends one
to the empty level ℓ + 1 and one to ℓ − 2, which then holds two. At the bottom,
if the last level of the pattern is 1 (p even), level 1 receives a chip, S2
puts one chip on each of the empty levels 0 and 2; if it is 0 (p odd), the
firing of level 2 gives level 0 two chips and C1 moves one chip to the empty
level 1. In both cases the result is Z_p.

(c) *Increment.* Let x be the lazy representation of n and p its lowest empty
level. If p = 0, x + e_0 is stable. If p ≥ 1, x + e_0 agrees with Y_p on levels
0..p and with x above p; by (b), stab(x + e_0) = (x above p) + Z_p. This
configuration has value n + 1 and no two consecutive empty levels: below p it
alternates and has a chip on p, and if level p lies below the top of x then
x_{p+1} = 1 (x is lazy and x_p = 0). Hence it is the lazy representation of
n + 1.

(d) By (a) and (c), stab((n + 1)e_0) = stab(stab(n e_0) + e_0)
= stab(lazy(n) + e_0) = lazy(n + 1), and induction from stab(0) = ∅ gives the
claim.

*Uniqueness of the lazy representation* (classical; e.g. Brown 1965): a lazy
string with top level t has value in [F_{t+2} − 1, F_{t+3} − 2] (alternating
string, resp. all ones), and these intervals partition the positive integers,
so t is determined by n; removing the top term leaves a lazy string of the
remainder, and induction applies. ∎

*Corroboration.* The split phase ends at the lazy digits for every n < 5000;
random firing orders never change the end point or the length (300 trials,
EXP-C19-02).

## Corollary 3 (CLM-C19-04) — a short proof of [C, Thm 1.4]

The game on n can be played with split moves only iff n = F_k − 1 (k ≥ 2).

*Proof.* A game using split moves only is a maximal split sequence (its end,
the Zeckendorf representation, admits no split move), so by Theorem 2 it exists
iff lazy(n) = Zeckendorf(n), i.e. iff the digit string has neither two adjacent
ones nor two adjacent zeros below the top: an alternating string 1010…, whose
value is F_{t+2} − 1 for top level t. ∎

## Theorem 4 (CLM-C19-03) — the longest game on a Fibonacci number

For the Fibonacci number on level j (n = F_{j+1}),

  L(F_{j+1}) = B(F_{j+1}) − ⌊j²/4⌋ = F_{j+3} − j − 3 − ⌊j²/4⌋,

i.e. in the paper's indexing L(F_k) = F_{k+2} − k − 2 − ⌊(k − 1)²/4⌋
(0, 1, 2, 5, 10, 20, 37, 67, 117, 201, …).

*Proof.* By [C, Thm 1.2] the strategy game is longest. Its first phase (split
moves while possible) ends at lazy(F_{j+1}) by Theorem 2. Since F_{j+1} − 1 has
the alternating representation with top level j − 1, Theorem 2(c) gives:
for j even, lazy(F_{j+1}) has chips on levels j − 1, j − 3, …, 3, 1, 0; for j
odd, on levels j − 1, j − 3, …, 4, 2, 1. No split move is available, so the
strategy combines the lowest adjacent pair: for j even C_2 (levels 0, 1 → 2);
the new chip lands on an empty level and is adjacent to the chip on level 3, so
the next move is C_4, and so on up to C_j (levels j − 2, j − 1 → j); no level
ever holds two chips, so no split occurs. For j odd the combines are
C_3, C_5, …, C_j. Hence Σ (i − 1)MC_i = 1 + 3 + … + (j − 1) = j²/4 (j even),
resp. 2 + 4 + … + (j − 1) = (j² − 1)/4 (j odd), and Theorem 1 gives the
formula with B(F_{j+1}) = a_{j+1} = F_{j+3} − j − 3. ∎

*Corroboration.* Greedy lengths for levels j ≤ 33 (EXP-C19-03); exhaustive
search for n ≤ 150 (EXP-C19-01).

## Conjecture 5 (CLM-C19-05) — a recursion for every n (COMPUTATIONALLY SUPPORTED)

Let h(k) = ⌊k²/4⌋ and define ρ_p (p ∈ {0, 1}) on ℕ by ρ_p(0) = 0 and, for
m = F_{i+1} + t (level i the top Zeckendorf level of m, 0 ≤ t < F_i),

  ρ_p(m) = r_p(i) + [i ≡ p (mod 2)] · max(0, ρ_p(t) − h(i − 2)),

with r_p(0) = 1, r_p(i) = h(i) + 2 if i ≥ 1 and i ≡ p, and r_p(i) = h(i + 1) + 1
if i ≢ p (mod 2). Then for every n = F_{j+1} + m with Zeckendorf top level j
(0 ≤ m < F_j)

  D(F_{j+1} + m) = h(j) + D(m) − ρ_{j mod 2}(m),   D(0) = 0,

and therefore L(n) = B(n) − D(n) can be computed with O(log² n) arithmetic
operations.

*Status.* Inferred from all n < 30000 (in-sample, 0 exceptions, EXP-C19-03) and
tested out of sample on 6272 further n, including all n in [30000, 36000) and
random n up to 2·10^7 (EXP-C19-04). The special case m = 0 is Theorem 4; the
case of two summands, D(F_{j+1} + F_{i+1}) = h(j) + h(i) − R(j, i) with
R(j, i) = ⌊(i + 1)²/4⌋ + 1 for odd j − i, ⌊i²/4⌋ + 2 for even j − i (i ≥ 1) and
R(j, 0) = 1, was checked for all 276 pairs with j ≤ 24. A proof would have to
analyse the second (normalisation) phase of the strategy game started from the
lazy representation (Theorem 2), where carries travel upward through
alternating blocks.

## Refuted hypotheses

* *H-C19-1* (D is the sum of h over the Zeckendorf levels minus pair savings
  R(j, i) of consecutive levels only): false already for n = 12 = F_5 + F_3 + F_1
  (levels 4, 2, 0): D(12) = 0 but the model gives 1 (EXP-C19-03).
* *H-C19-2* (the effect of the top summand depends only on the two highest
  levels): false — (top, next) = (4, 2) occurs with two different values
  (EXP-C19-03).
* *H-C19-3* (D is additive over the runs of the lazy representation): the linear
  system for n < 160 is inconsistent (EXP-C19-03).
* *H-C19-4* (L(n + 1) = L(n) + λ(n), λ(n) the longest game from
  Zeckendorf(n) + F_1): false for n = 3: L(4) = 3, L(3) = 2, λ(3) = 0
  (EXP-C19-02); it fails for 288 of the first 300 n.
