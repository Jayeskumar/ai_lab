# Cycle C09 — Written proofs (arithmetic of Knuth's circle semigroup)

Notation as in `proofs/paper/C08.md`: Z(n) Zeckendorf indices (≥ 2),
n* = Σ_{k∈Z(n)} F_{k−1} (the *shadow*), ν(n) = nφ + n* = Σ_{k∈Z(n)} φ^k and
ν′(n) = nψ + n* = Σ_{k∈Z(n)} ψ^k. Knuth's product is a∘b = ∘_0 (s = 2 in
G-indexing). Facts from C08 Theorem 1 (t = 0): ν(a∘b) = ν(a)ν(b),
ν′(a∘b) = ν′(a)ν′(b), and ν′(n) ∈ (−ψ², −ψ) for all n ≥ 1.

## Theorem 1 (CLM-C09-01) — structure

(ℕ≥1, ∘) is a commutative, cancellative semigroup without identity; ν is an
injective homomorphism into the multiplicative monoid of ℤ[φ]. The Fibonacci
numbers F_k (k ≥ 2) are exactly the n whose ν(n) is a unit, F_j∘F_k = F_{j+k},
and n ↦ N(n) := ν(n)ν′(n) = n*² + n·n* − n² is a homomorphism to (ℤ, ·) with
N(n) = ±1 iff n is a Fibonacci number. Explicitly a∘b = ab + ab* + a*b and
(a∘b)* = ab + a*b*, with n* = ⌊(n+1)/φ⌋.

*Proof.* Associativity is C08 Theorem 1; commutativity is clear. ν is
injective because n is the φ-coordinate of ν(n) in the basis (φ, 1).
Cancellation: ν(a)ν(b) = ν(a)ν(c) in the domain ℤ[φ] with ν(a) ≠ 0 gives
ν(b) = ν(c), so b = c. No identity: a∘b ≥ 1∘b > b (1∘b shifts every
Zeckendorf index up by 2). Units: ℤ[φ] is the ring of integers of ℚ(√5), whose
units are ±φ^k; ν(n) > 0, and ν(n) = φ^k = F_kφ + F_{k−1} forces n = F_k
(k ≥ 2 since Z(n) ⊂ [2, ∞)); conversely Z(F_k) = {k} so ν(F_k) = φ^k, and
F_j∘F_k = F_{j+k} by definition. N is the field norm restricted to ν(ℕ), hence
multiplicative, and N(n) = ±1 iff ν(n) is a unit. Expanding
(aφ + a*)(bφ + b*) with φ² = φ + 1 gives the formulas for a∘b and (a∘b)*.
Finally ν′(n) = nψ + n* ∈ (−ψ², −ψ) with ψ = −1/φ means
n* ∈ ((n+1)/φ − 1, (n+1)/φ), i.e. n* = ⌊(n+1)/φ⌋. ∎

## Refutation (CLM-C09-02) — factorisation is not unique

8 = 1∘1∘1 = 2∘2, and 1, 2 are irreducible (every product is ≥ 1∘1 = 3).
The two factorisations even have different lengths. Mechanism: 1 = F_2 and
2 = F_3, and F_j∘F_k = F_{j+k}, so factorisations of F_k into 1s and 2s are the
factorisations of k in the numerical semigroup ⟨2, 3⟩.

## Theorem 3 (CLM-C09-03) — the window obstruction and density 1/φ²

If n is reducible then ν′(n) ∈ (ψ³, ψ²). Writing f(n) = {(n+1)/φ}, this says
f(n) ∈ (1/φ − ψ², 1/φ − ψ³) = (0.2360…, 0.8541…). Consequently every n with
f(n) ∉ (0.2360…, 0.8541…) is circle-irreducible, and these n have natural
density exactly ψ² = 1/φ² ≈ 0.381966. In particular the irreducibles have
lower density ≥ 1/φ².

*Proof.* If n = a∘b then ν′(n) = ν′(a)ν′(b) with both factors in
(−ψ², −ψ) ≈ (−0.382, 0.618); the product of two such numbers lies in
(ψ²·ψ, ψ²) = (ψ³, ψ²) (extreme cases: (−ψ²)(−ψ) = ψ³ < 0 and (−ψ)² = ψ²).
From n* = ⌊(n+1)/φ⌋ and ψ = −1/φ, ν′(n) = n* − n/φ = 1/φ − f(n). The
condition ψ³ < 1/φ − f < ψ² is f ∈ (1/φ − ψ², 1/φ − ψ³), an interval of length
ψ² − ψ³ = ψ²(1 − ψ) = ψ²φ = −ψ = 1/φ. Since 1/φ is irrational, (n+1)/φ mod 1
is equidistributed (Weyl), so the complement has density 1 − 1/φ = 1/φ². ∎

*Numerical check.* EXP-C09-04: no reducible n ≤ 10⁶ outside the zone; the
forced-irreducible density at 10⁶ is 0.381966. (Floating-point decisions are
safe: the only exact boundary values are ν′(1) = ψ² and ν′(2) = ψ³, both for
irreducible numbers, and otherwise |ν′(n) − boundary| = |(n−1)ψ − p| ≥ 0.4/n
because φ is badly approximable.)

## Theorem 4 (CLM-C09-06) — a length bound for factorisations

If n = a_1∘…∘a_r then |ν′(n)| < |ψ|^r. Hence every factorisation of n has
length r < log|ν′(n)| / log|ψ| (finite since ν′(n) ≠ 0 for n ≥ 1), and
(ℕ≥1, ∘) is a BF-semigroup (bounded factorisation lengths).

*Proof.* ν′ is multiplicative and each |ν′(a_i)| < max(ψ², −ψ) = −ψ = |ψ|.
ν′(n) ≠ 0 because ν′(n) = nψ + n* with ψ irrational and n ≥ 1. ∎

## Conjecture 5 (CLM-C09-05) — the density of circle irreducibles is 1/φ²

Within the product zone the proportion of irreducibles tends to 0, so the
irreducibles have density exactly 1/φ². *Evidence:* the irreducible fraction
inside the zone is 0.316, 0.291, 0.270, 0.255 at 10³, 10⁴, 10⁵, 10⁶; overall
irreducible density 0.539 at 10⁶ (decreasing). Low confidence about the rate.
