# Cycle C16 — Written proofs (Fibonacci dynamics in finite magmas)

Setting. M = {0, …, n − 1} with a binary operation ⋆ (table T[a, b] = a ⋆ b).
The *Fibonacci recurrence* is x_{k+1} = x_k ⋆ x_{k−1}; its state is the pair
(x_{k−1}, x_k), and the *pair map* is P(a, b) = (b, b ⋆ a) on the n² states.
L_b(a) = b ⋆ a is the left translation by b. A table is *full-period* if P is a
single cycle through all n² states. Code: `systems/magma_dynamics.py`; Lean:
`proofs/lean/Infinity/C16_Dynamics.lean`.

Every function f : M × M → M is the feedback of exactly one magma
(T[b, a] = f(a, b)), so the pair maps of n-element magmas are exactly the
order-2 feedback shift registers over an n-letter alphabet. Several statements
below are therefore translations of shift-register facts; we say so.

---

## Theorem 1 (CLM-C16-01) — when the pair map is a permutation

P is a bijection iff every left translation L_b is a bijection. Hence exactly
(n!)^n of the n^(n²) tables have a permutation as pair map. The mirror
recurrence x_{k+1} = x_{k−1} ⋆ x_k is the forward recurrence of the opposite
operation a ∘ b := b ⋆ a.

*Proof.* If P(a, b) = P(a′, b′) then b = b′ and L_b(a) = L_b(a′), so a = a′
when L_b is injective. If L_b(a) = L_b(a′) with a ≠ a′, then
P(a, b) = P(a′, b). On a finite set injective means bijective. Each row of a
table with bijective rows is one of n! permutations, independently. The mirror
statement is a rewriting of definitions. ∎ (Lean: `pairMap_injective_iff`,
`pairMap_bijective_iff`, `mirrorMap_eq`.) This is the q-ary form of Golomb's
nonsingularity criterion for feedback shift registers (S. W. Golomb, *Shift
Register Sequences*, 1967). EXP-C16-01: 4, 216, 331776 permutation pair maps
for n = 2, 3, 4, as predicted; 0 violations of the criterion.

## Theorem 2 (CLM-C16-03) — full period is the same thing as a de Bruijn cycle

A table is full-period iff the cyclic sequence of symbols along its single
cycle is a de Bruijn cycle of order 2 over M (every ordered pair occurs exactly
once as two consecutive symbols), and table ↦ cycle is a bijection between
full-period tables and de Bruijn cycles (up to rotation). Consequently there
are exactly (n!)^n / n² full-period tables of order n, and the maximal period of
the pair map over all n-element magmas is n² for every n ≥ 1.

*Proof.* If P is one cycle of length n², following it from any state lists
x_0, x_1, …, x_{n²−1} cyclically, and the consecutive pairs (x_i, x_{i+1}) are the
n² states, each once. Conversely, given a de Bruijn cycle, let f(a, b) be the
symbol following the unique occurrence of (a, b); the table T[b, a] = f(a, b)
has the cycle as its single orbit. The two constructions are inverse to each
other. The number of de Bruijn cycles of order m over k symbols is
(k!)^(k^(m−1)) / k^m (T. van Aardenne-Ehrenfest and N. G. de Bruijn, Simon Stevin
28 (1951); the BEST theorem); for m = 2 this is (k!)^k / k² > 0. ∎ EXP-C16-01
counts 1, 24 and 20736 full-period tables for n = 2, 3, 4, exactly the
formula. The example for n = 2 is x ⋆ y = 1 − y (x_k = 0, 0, 1, 1, …).

*Refutation of H-C16-1* ("as for Pisano periods, the maximal period is at most
n² − 1, attained only by quasigroups"): n = 2, x ⋆ y = 1 − y has period 4 and is
not a quasigroup; none of the 24 full-period tables of order 3 and none of the
20736 of order 4 is a quasigroup.

## Theorem 3 (CLM-C16-04) — a parity condition

If every L_b is a bijection, then sign(P) = (−1)^(n(n−1)/2) · ∏_b sgn(L_b). In
particular a full-period table satisfies

  ∏_b sgn(L_b) = (−1)^((n−1)(n+2)/2).

*Proof.* P = S ∘ R with R(a, b) = (L_b(a), b) and S(x, y) = (y, x). R permutes
each fibre {(·, b)} by L_b, so sgn(R) = ∏_b sgn(L_b); S fixes the n diagonal
pairs and swaps the other n(n − 1) in transpositions, so
sgn(S) = (−1)^(n(n−1)/2). An n²-cycle has sign (−1)^(n²−1), and
n² − 1 − n(n − 1)/2 = (n − 1)(n + 2)/2. ∎ (Every full-period table found in
EXP-C16-01/02 satisfies it.)

## Theorem 4 (CLM-C16-05) — full-period quasigroups are distance-2 de Bruijn cycles

A full-period table is a quasigroup iff, in its cycle x_0 … x_{n²−1}, every ordered
pair also occurs exactly once at distance 2, i.e. as (x_i, x_{i+2}).
Equivalently, the n² windows (x_{i−1}, x_i, x_{i+1}) run exactly once through the
triples (a, b, b ⋆ a) of the Latin square: the cycle is a universal cycle of the
quasigroup.

*Proof.* The rows L_b of a full-period table are bijections by Theorem 1. The
columns are the maps b ↦ b ⋆ a. Each symbol a occurs n times in the cycle, and at
an occurrence x_{i−1} = a we have x_{i+1} = x_i ⋆ a, where x_i runs through all n
symbols (the pairs (a, x_i) are distinct). So the column b ↦ b ⋆ a is injective
iff the n pairs (a, x_{i+1}) at distance 2 starting with a are distinct; over all
a this says that the n² distance-2 pairs are distinct, i.e. each occurs once. ∎

## Theorem 5 (CLM-C16-07) — which orders have full-period quasigroups (computer-assisted)

There is no full-period quasigroup of order 2, 3 or 4; there are exactly 3360
of order 5 (28 isomorphism classes, each of size 5! = 120); full-period
quasigroups of every order 6, 7, …, 16 exist, and so do quasigroups of orders
30, 35, 40, 42, 45, 56, 63, 72 (Theorem 6).

*Proof (computer-assisted, EXP-C16-02).* All 2, 12, 576 and 161280 Latin squares
of orders 2–5 were analysed; independently, a depth-first enumeration of cyclic
sequences with all distance-1 and distance-2 pairs distinct (normalised to begin
with 0, 0, which every such cycle contains exactly once) gives the same counts
0, 0, 0, 3360 (Theorem 4 makes the two counts equal). For orders 6–16 each
example was found by seeded sampling and re-verified by an independent cycle
analysis (single cycle of length n², Latin). ∎

*Refutation of H-C16-5* ("no quasigroup is full-period; the quasigroup maximum
is n² − 1"): it holds for n ≤ 4 and fails from n = 5 on.

## Theorem 6 (CLM-C16-08) — products of coprime orders

If (M₁, ⋆₁) and (M₂, ⋆₂) are full-period of coprime orders n₁, n₂, the direct
product is full-period; if both are quasigroups, so is the product.

*Proof.* The pair map of the product is the product of the pair maps, acting
componentwise on ((a₁, a₂), (b₁, b₂)) ≅ ((a₁, b₁), (a₂, b₂)). The product of a
cycle of length n₁² and a cycle of length n₂² is a single cycle of length n₁²n₂²
when gcd(n₁², n₂²) = 1 (Chinese remainder theorem). Products of quasigroups are
quasigroups. ∎ (Verified for the eight products of EXP-C16-02.)

## Theorem 7 (CLM-C16-09) — no isotope of a group of even order is full-period

Let G be a group of even order n = 2m and x ∘ y = γ(α(x)·β(y)) any isotope
(α, β, γ permutations of G). Then ∏_b sgn(L_b) = (−1)^m, while Theorem 3
requires (−1)^((2m−1)(m+1)) = (−1)^(m+1). So no isotope of a group of even order
— in particular no group of even order — has a full-period pair map.

*Proof.* L_b = γ ∘ λ_{α(b)} ∘ β with λ_g(y) = g·y, so
∏_b sgn(L_b) = sgn(γ)^n sgn(β)^n ∏_{g∈G} sgn(λ_g) = ∏_g sgn(λ_g) (n even). λ_g
has n/o(g) cycles of length o(g), so sgn(λ_g) = (−1)^(n − n/o(g)) = (−1)^(n/o(g)).
Let 2^k ‖ n. Then n/o(g) is odd iff 2^k | o(g). If the Sylow 2-subgroups are
cyclic, Burnside's normal p-complement theorem gives G = N ⋊ C_{2^k} with |N| odd,
and the elements with 2^k | o(g) are those mapping onto a generator of C_{2^k}:
there are φ(2^k)·|N| = 2^(k−1)·n/2^k = m of them. If the Sylow 2-subgroups are not
cyclic, no element has order divisible by 2^k, and m is even because 4 | n. In
both cases the number of g with n/o(g) odd has the parity of m. ∎
(EXP-C16-02: 2000 random isotopes of each of Z4, Z2², Z6, S3, Z8, Z2 × Z4, Z2³,
D4, Q8 — row-sign product always (−1)^m, never full-period. For odd n the
obstruction disappears, and isotopes of Z_n are full-period for every odd
n from 5 to 15.)

## Theorem 8 (CLM-C16-11) — fixed points are idempotents

P(a, b) = (a, b) iff a = b and a ⋆ a = a. Hence an idempotent magma has n
fixed points and maximal period at most n² − n; no idempotent quasigroup is
full-period. ∎ (Lean: `pairMap_fixed_iff`.)

## Theorem 9 (CLM-C16-12) — affine magmas

Let x ⋆ y = αx + βy + γ on ℤ/N. Then P(v) = Cv + c with C = [[0, 1], [β, α]] and
c = (0, γ).
(a) If (α + β − 1)x* + γ = 0 has a solution, translation by (x*, x*) conjugates
P to the linear map C, and the maximal period is ord(C) in GL₂(ℤ/N) (β a unit).
(b) In general the order of the affine matrix Â = [[C, c], [0, 1]] is the least
common multiple of all orbit lengths, so every period divides it.
In particular: the anchored associative magma x + y + 1 (x* = −1) has exactly
the cycle structure of the Fibonacci numbers modulo N, maximal period the
Pisano period π(N); the odd-law magma x + 1 + y/2 (x* = −2) has maximal period
ord([[0, 1], [1/2, 1]]); the golden-law magmas x + 1 + a y with a² + a = 1
(x* = −1/a) have maximal period ord([[0, 1], [a, 1]]).

*Proof.* (a) P(v* + w) = Cv* + c + Cw = v* + Cw. For C the vector e₂ = (0, 1)
is cyclic: e₂ and Ce₂ = (1, α) form a basis (determinant −1). If C^k e₂ = e₂,
then also C^k(Ce₂) = C(C^k e₂) = Ce₂, so C^k fixes a basis and C^k = I; hence
the orbit of e₂ has length ord(C), and no orbit is longer. (b) Â^k fixes every
vector (v, 1) iff Â^k = I, because these vectors generate (ℤ/N)³. ∎ (Lean for
the anchored conjugacy: `anchored_fibonacci`.) EXP-C16-03 confirms (a) for all
anchored N ≤ 60, odd N ≤ 61 and all 51 golden pairs (N, a) with N ≤ 200. The
maximal periods of the odd and golden laws (6, 24, 48, 18, 5, 12, … for
N = 3, 5, 7, …; 4, 120, 342, … for N = 5, 11, 19, …) are not in the OEIS. That
periods of linear recurrences modulo N are orders of companion matrices is
classical (M. Ward, Trans. AMS 35 (1933); D. D. Wall, Amer. Math. Monthly 67
(1960)).

*Conjecture (CLM-C16-13).* For every affine magma with β a unit, the maximal
period equals ord(Â) (true in 300 of 300 random cases, N ≤ 30).

## Theorem 10 (CLM-C16-14) — Fibonacci sequences of nimbers

On [0, q) with q = 2^(2^k), nim-multiplication makes a field (Conway). Its pair
map sends every pair containing 0 to (0, 0) within two steps, and on nonzero
pairs it is isomorphic, via logarithms to a primitive element, to the Fibonacci
pair map on (ℤ/(q − 1))². Hence the maximal period is the Pisano period
π(q − 1): 40 for q = 16 and 360 for q = 256. ∎ (x_k = g^(e_k) gives
e_{k+1} = e_k + e_{k−1}.) This is the Fibonacci length of a cyclic group, a
classical fact.

## Theorem 11 (CLM-C16-15) — Laver tables collapse to 2-cycles

For n ≥ 1 and N = 2^n, the pair map of the Laver table A_n (0-based, anchored
x ⋆ 0 = x + 1) has exactly N cycles: the fixed point (N − 1, N − 1) and the N − 1
two-cycles {(N − 1, c), (c, N − 1)}. Every orbit reaches one of them.

*Proof.* We use three standard facts about A_n (Laver; see P. Dehornoy, *Braids
and Self-Distributivity*, 2000, Ch. X): (N − 1) ⋆ y = y, x ⋆ (N − 1) = N − 1, and
x ⋆ y > x for x < N − 1. By the first two, (N − 1, c) ↦ (c, N − 1) ↦ (N − 1, c)
(Lean: `top_two_cycle`). If x_k < N − 1 then x_{k+1} = x_k ⋆ x_{k−1} > x_k, so the
sequence increases strictly until it reaches N − 1, after which the state
contains N − 1 and lies on one of the cycles above; a state without N − 1 is
therefore never periodic. ∎ (EXP-C16-03: confirmed for n ≤ 10; the longest
transient is 5 for every 4 ≤ n ≤ 10.) In particular the bold hypothesis H-C16-4
("the maximal period of A_n is a power of 2") is true, for the degenerate
reason that it is 2.
