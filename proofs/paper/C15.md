# Cycle C15 — Written proofs (magma cellular automata)

Setting. A finite magma (M, *) with |M| = n defines the automaton c′ᵢ = cᵢ * cᵢ₊₁ on
cyclic rows (indices mod L) or one-sided infinite rows. The t-step local map is
F₀(x₀) = x₀ and F_t(x₀, …, x_t) = F_{t−1}(x₀, …, x_{t−1}) * F_{t−1}(x₁, …, x_t); cell i
at time t is F_t(c_i, …, c_{i+t}). The *forward width* of F_t is the largest number of
distinct residual functions (x_k, …, x_t) ↦ F_t(a₀, …, a_{k−1}, x_k, …, x_t) over
prefixes a of a fixed length k (the level width of the reduced ordered BDD); the
*backward width* reads from the right; the *streaming width* λ(t) is the smaller
of the two. It is invariant under isomorphism and anti-isomorphism (the mirror
image). Code: `systems/magma_ca.py`; Lean: `proofs/lean/Infinity/C15_MagmaCA.lean`.

## Theorem 1 (CLM-C15-01) — light cones of semigroups

(a) If * is associative, F_t(x₀, …, x_t) = ∏_{j=0}^{2^t−1} x_{s(j)} (ordered product),
where s(j) is the number of ones in the binary expansion of j.
(b) If moreover * is commutative, F_t(x₀, …, x_t) = ∏_{k=0}^{t} x_k^{C(t,k)}.
(c) For a commutative semigroup S, the forward and backward widths of every F_t
are at most |S|.

*Proof.* (a) Induction on t; t = 0 is trivial. By associativity F_t is the product
of the word w_{t−1}(x₀, …, x_{t−1}) followed by w_{t−1}(x₁, …, x_t). The indices
j < 2^{t−1} (leading binary digit 0) give the letters x_{s(j)} of the first word;
j = 2^{t−1} + j′ gives the letter x_{1+s(j′)} = x_{s(j)} of the second. (b) Exactly
C(t, k) of the j < 2^t have s(j) = k; regroup using commutativity. (Lean,
`ca_comm_binomial`, for commutative monoids; a commutative semigroup embeds in the
commutative monoid S¹ obtained by adjoining an identity, and all exponents
C(t, k) are ≥ 1, so the formula holds in S.) (c) After reading x₀, …, x_{k−1}
(1 ≤ k ≤ t + 1) the residual is y ↦ p · ∏_{j ≥ k} y_j^{C(t,j)} with
p = ∏_{j<k} x_j^{C(t,j)} ∈ S, so there are at most |S| residuals per level; the
same argument applies from the right. ∎

## Theorem 2 (CLM-C15-02) — affine magmas and their fast-forward

Let A be an abelian group, φ, ψ commuting endomorphisms and c ∈ A, and
x * y = φ(x) + ψ(y) + c. Then
(a) F_t(x₀, …, x_t) = Σ_{k=0}^{t} C(t,k) φ^{t−k}ψ^k(x_k) + Σ_{s<t} (φ + ψ)^s(c);
(b) on a cyclic row r of length L, the row at time t is P^t r + Σ_{s<t} q^s c·𝟙,
where P = φ + ψS in End(A)[S]/(S^L − 1), S the left shift ((Sr)_i = r_{i+1}),
and q = φ + ψ acting on the constant row; P^t is computed with O(log t)
multiplications in End(A)[S]/(S^L − 1); for A = ℤ/n each multiplication is a
cyclic convolution, O(L log L) by FFT;
(c) the forward and backward widths of F_t are at most |A|.

*Proof.* (a) Induction: F_{t+1} = φ(F_t(x₀..x_t)) + ψ(F_t(x₁..x_{t+1})) + c, and since
φ and ψ commute, φ^{t−k+1}ψ^k(C(t,k) + C(t,k−1)) = C(t+1,k)φ^{t+1−k}ψ^k (Pascal);
the constant obeys g_{t+1} = (φ + ψ)(g_t) + c. (b) One step is r ↦ Pr + c𝟙, so
r_t = P^t r + Σ_{s<t} P^s c𝟙, and P𝟙 = (φ + ψ)𝟙 because S𝟙 = 𝟙. Binary
exponentiation needs ⌊log₂ t⌋ squarings and at most as many multiplications.
(c) The residual after a prefix is determined by the partial sum of the prefix
terms, an element of A. ∎

This is the classical theory of linear cellular automata (Martin, Odlyzko and
Wolfram 1984) in operator form; we use it as the baseline fast-forward.

## Theorem 3 (CLM-C15-03) — commutative semigroups: exponent arithmetic

Let S be a finite commutative semigroup, r a cyclic row of length L and
t ≥ 2L + ι + 1, where ι is the largest index of a cyclic subsemigroup ⟨x⟩. Then
cell i at time t equals ∏_{j=0}^{L−1} r_{i+j}^{e_j}, where N_j is the coefficient
of S^j in (1 + S)^t modulo S^L − 1, π is the least common multiple of the periods
of the elements, and x^{e} for the true exponent N_j is computed as
x^{ι_x + ((N_j − ι_x) mod π_x)}, which only needs N_j mod π.

*Proof.* By Theorem 1(b) cell i at time t is ∏_{k=0}^{t} r_{i+k}^{C(t,k)}; grouping k by
its residue j mod L gives exponents N_j = Σ_{k ≡ j} C(t, k), the coefficients of
(1 + S)^t mod S^L − 1. For t ≥ 2L + ι + 1 every N_j ≥ ι: for 1 ≤ j < L the term
C(t, j) ≥ t; for j = 0 the term C(t, L) ≥ t. In a cyclic semigroup with index ι_x
and period π_x, x^m for m ≥ ι_x depends only on m mod π_x, and π_x divides π. ∎

The final product costs O(L²) table look-ups, which is why this method loses to
direct simulation for moderate t (EXP-C15-03).

## Theorem 4 (CLM-C15-04) — the fuse magma: linear streaming width, constant-time fast-forward

The *fuse* magma on {0, 1, 2} has 0 * y = 0; 1 * y = 1 if y = 2, else 0; 2 * y = 2
if y ≠ 0, and 2 * 0 = 1 (table [[0,0,0],[0,0,1],[1,2,2]]; a cell 2 is an intact
fuse, 1 a burning cell, 0 a burnt one).

(a) *Burn times.* For any row, let τ_i = min{t : c_i(t) = 0} (∞ if none). Then
τ_i = 0 if x_i = 0; τ_i = τ_{i+1} + 2 if x_i = 2; τ_i = τ_{i+1} if x_i = 1 and
x_{i+1} = 2; τ_i = 1 if x_i = 1 and x_{i+1} ≠ 2. Moreover, if x_i = 2 then
c_i(t) = 2 for t ≤ τ_{i+1}, c_i(τ_{i+1} + 1) = 1 and c_i(t) = 0 afterwards; if
x_i = 1 then c_i(t) = 1 exactly for t < τ_i.
(b) *Fast-forward.* On a cyclic row of length L the row at any time t can be
computed in O(L) operations: compute all τ_i in one backward pass around the
cycle from the cells with τ_i ∈ {0, 1}, then read off c_i(t) from (a).
(c) *Width.* For t ≥ 2, with m = ⌊t/2⌋,
  ⌊(m + 1)/2⌋ ≤ λ(t) ≤ 3t + 3.
In particular the streaming width is unbounded and grows only linearly. (The
computed values are λ(t) = t + 2 for 1 ≤ t ≤ 12, EXP-C15-05.)

*Proof.* (a) 0 is left-absorbing, so a burnt cell stays burnt. If x_i = 2, the
cell stays 2 while its right neighbour is nonzero, i.e. at the times
t + 1 ≤ τ_{i+1}; at τ_{i+1} + 1 it becomes 2 * 0 = 1, and at τ_{i+1} + 2 it becomes
1 * 0 = 0 because the neighbour stays 0. Hence τ_i = τ_{i+1} + 2. If x_i = 1, the
cell stays 1 exactly while its right neighbour has been 2 at every earlier time.
If x_{i+1} ≠ 2 it dies at time 1. If x_{i+1} = 2, the neighbour is 2 exactly at
the times ≤ τ_{i+2}, so the cell is 1 up to time τ_{i+2} + 1 and 0 from
τ_{i+2} + 2 = τ_{i+1} on.
(b) Cells with x_i = 0, or x_i = 1 followed by a non-2, have τ_i ∈ {0, 1}; every
other cell copies or increases the value of its right neighbour, so a single
pass leftwards from such a seed fixes all values (if there is no seed, every τ_i
is ∞: the row is a fixed pattern of 2s and blocks 12, which never changes).
(c) *Lower bound.* Take the prefixes P_b = 2 (12)^b 2^{m−1−2b} of length m
(0 ≤ b ≤ ⌊(m−1)/2⌋) and the suffixes Q_j = 2^j 0 2^{t−m−j} of length t + 1 − m
(0 ≤ j ≤ t − m). In the row P_b Q_j the cell m + j is 0, so τ_m = 2j and, since
the cells 1, …, m−1 contain m − 1 − b letters 2 (each adds 2) and b blocks 12
(each block adds 2 over two cells), τ₁ = 2j + 2(m − 1 − b). As x₀ = 2,
F_t(P_b Q_j) = 2 iff t ≤ τ₁ iff j ≥ b + 1 + (t − 2m). The threshold is strictly
increasing in b, so the residuals of the prefixes P_b are pairwise distinct
(forward width ≥ ⌊(m−1)/2⌋ + 1 = ⌊(m+1)/2⌋), and symmetrically the residuals of
the suffixes Q_j, j = (t − 2m), …, ⌊(m−1)/2⌋ + (t − 2m), as functions of the
prefix are pairwise distinct (backward width ≥ the same number).
*Upper bound.* Reading from the right, after the suffix x_k, …, x_t the residual
(a function of x₀, …, x_{k−1}) depends only on x_k and on min(τ_k, t) (τ_k computed
inside the suffix, ∞ if it contains no seed): by (a) the output at time t only
compares t with τ₁ or τ₂ + 1, which equal τ_k plus a prefix-determined amount,
and all values ≥ t behave alike. That gives at most 3(t + 1) residuals per level,
so λ(t) ≤ 3t + 3. ∎

*Remark.* The forward width is also O(t): the residual after a prefix depends on
x₀, on whether a seed has occurred (then it is constant), on the accumulated
offset 2·#2s capped at t + 1, and on whether the last letter is 1.

## Theorem 5 (CLM-C15-05) — surjective iff permutive, for |M| ≤ 3

For |M| ≤ 3 the automaton is surjective on bi-infinite rows iff all rows or all
columns of the table are permutations. Hence there are 2(n!)^n − Lat(n) surjective
tables of order n = 1, 2, 3 (1, 6, 420; Lat(n) = number of Latin squares). For
n = 4 the rectangular band (b, c) * (b′, c′) = (b, c′) on {0, 1}² is surjective and
even injective, but neither its rows nor its columns are permutations.

*Proof.* "Permutive ⇒ surjective" is Hedlund's theorem (a two-cell rule that is
bijective in its first or last variable is onto). The converse for n ≤ 3 is
computer-assisted: the Garden-of-Eden theorem (Moore–Myhill) makes surjectivity
equivalent to the absence of a "diamond" in the pair graph (vertices M × M, an
edge (u, v) → (u′, v′) when u * u′ = v * v′; a diamond is a path that leaves the
diagonal and returns to it), which is decided exactly for all 1734 classes of
order 3 and all 16 tables of order 2 (EXP-C15-01/02; both properties are
invariant under isomorphism and mirror image). For n = 4 the automaton acts as the
identity on the first coordinate and as the shift on the second, a bijection of
bi-infinite rows; a row of the table, y ↦ (b, c) * y = (b, y₂), ignores y₁. ∎

This is a special case of the theorem of Kari, Salo and Törmä (2013): a surjective
two-neighbour automaton over a prime alphabet is permutive in some coordinate.

## Theorem 6 (CLM-C15-06) — order 2

The 16 automata of two-element magmas are exactly the elementary rules that
ignore the left neighbour, i.e. the Wolfram numbers 17m (m = 0, …, 15): the rule
number of a magma is Σ_{l,c,r} (c * r) 2^{4l+2c+r} = 17 Σ_{c,r} (c * r) 2^{2c+r}. ∎
