# Cycle C20 — Written proofs (open problems revisited)

## Part I — the last open one-rule systems of C04

Cycle C04 classified all 868 one-rule systems l → r over {a, b} with
|l| ≤ 3, |r| ≤ 5, except two symmetry classes: aab → ababa and aab → babaa
(with their images under reversal and the letter exchange a ↔ b, 8 rules).
We prove that all of them terminate and determine their derivational
complexity D(n) = max{D(w) : |w| = n} exactly.

**Common tools.** (RD) aab is unbordered, so l → r has random descent
(C04 Theorem 4, Lean `unbordered_random_descent`): if some derivation from w
ends in a normal form after n steps, then every derivation from w has at most
n steps and every maximal derivation has exactly n steps. Hence termination
and D(w) can be read off any single strategy; we use the *rightmost* strategy
(always rewrite the rightmost occurrence of aab).

*(Run encoding.)* Write w = a^{x_0} b a^{x_1} b ⋯ b a^{x_m} (m = number of b's,
x_i ≥ 0). An occurrence of aab ends at the (k+1)-th b and exists iff x_k ≥ 2
(k < m); the last run x_m is never part of a redex.

---

### Theorem 1 (CLM-C20-01) — aab → ababa terminates, and D(n) = 2^{n−2} − 1 (n ≥ 2)

A step at run k replaces (…, x_k, x_{k+1}, …) by (…, x_k − 1, 1, x_{k+1} + 1, …):
run k loses one a, a new run of length 1 is inserted, the next run gains one
a, and m grows by one.

*Units and journeys.* Call u(w) = Σ_{k<m, x_k ≥ 1} (x_k − 1) the number of
*units* (surplus a's in non-final runs). Under the rightmost strategy let k be
the rightmost redex; then every run strictly between k and the last run has
value ≤ 1. After the step the receiving run (old k + 1) has value
x_{k+1} + 1: if it had value 1 and is not the last run it becomes the new
rightmost redex (value 2); if it had value 0 (a *hole*) or is the last run,
no redex remains to the right of k. Call the maximal chain of steps that
passes the surplus a from run to run a *journey*. Along a journey the number
of b's to the right of the firing run drops by one per step (the new b is
inserted to the left of the receiving run), so a journey is finite and has at
most as many steps as there are b's to the right of its starting run. Each run
it passes returns to value 1; inserted runs have value 1; the journey ends by
filling a hole (0 → 1) or entering the inert last run. So u decreases by
exactly one per journey and never increases (holes are never created).

*Termination.* The rightmost strategy performs u(w) finite journeys and stops
when u = 0, i.e. at a normal form. By (RD) every derivation from w is finite,
of the same length.

*Upper bound.* Let A₀, B₀ be the numbers of a's and b's in w (A₀ + B₀ = n).
Each step inserts one b, so D(w) = B_final − B₀. A journey starting with B b's
has at most B steps, so B at most doubles per journey. If no non-final run is
nonempty there is no redex; otherwise u(w) ≤ A₀ − 1. Hence
D(w) ≤ B₀(2^{A₀−1} − 1) = B₀(2^{n−B₀−1} − 1) ≤ 2^{n−2} − B₀ ≤ 2^{n−2} − 1,
using B·2^{n−B−1} ≤ 2^{n−2}, i.e. B ≤ 2^{B−1}, for B ≥ 1.

*Lower bound.* For w = a^{n−1} b there are no holes and the last run is empty:
every journey starts at run 0, passes only runs of value 1 and ends in the
last run, so it has exactly as many steps as there are b's, which double:
1, 2, 4, …, 2^{n−3} over the u = n − 2 journeys, in total 2^{n−2} − 1. ∎

### Theorem 2 (CLM-C20-02) — aab → babaa terminates; an exact formula for D(w)

A step at run k replaces (…, x_k, x_{k+1}, …) by (…, x_k − 2, 1, x_{k+1} + 2, …).
Under the rightmost strategy the receiving run gets value x_{k+1} + 2 ≥ 2, so
unless it is the last run it fires next and passes the two a's on, returning
to its old value x_{k+1}. Thus a *journey* carries a pair of a's from run k
all the way into the last run, in exactly d steps, d = number of b's to the
right of run k; it inserts d new b's (all to the right of run k), leaves run
k with x_k − 2 and creates no redex to the right of k. Consequently run k,
once it holds the rightmost redex, performs ⌊x_k/2⌋ journeys of lengths
d, 2d, 4d, … and keeps x_k mod 2 ≤ 1 a's; runs to its left are untouched
meanwhile. Processing runs from right to left gives

  D(w) = Σ_{k=m−1}^{0} d_k (2^{⌊x_k/2⌋} − 1),   d_k = (m − k) + Σ_{k′>k} (steps of run k′),

which is finite; by (RD) every derivation from w is finite with this length.

*Complexity.* Each journey has at most as many steps as there are b's, so B
at most doubles per journey; there are Σ_k ⌊x_k/2⌋ ≤ ⌊A₀/2⌋ journeys. Hence
D(w) ≤ B₀(2^{⌊(n−B₀)/2⌋} − 1), and w = a^{n−B} b^{B} attains it (one run, d = B).
Therefore D(n) = max_{1 ≤ B ≤ n} B(2^{⌊(n−B)/2⌋} − 1) = Θ(2^{n/2}). ∎

*Explicit form (from the Skeptic's review, checked by the Director).* The
maximum is attained at B = 2 for even n and at B = 3 for odd n ≥ 5 (B = 1 ties
at n = 5), so D(n) = 2^{n/2} − 2 for even n ≥ 2 and D(n) = 3·2^{(n−3)/2} − 3
for odd n ≥ 5 (D(1) = 0, D(3) = 1). Indeed, for even n, B = 1 gives
2^{(n−2)/2} − 1, B = 3 gives (3/4)·2^{n/2} − 3 and B = 4 gives 2^{n/2} − 4, all
smaller than 2(2^{(n−2)/2} − 1) = 2^{n/2} − 2, and larger B lose a further
factor; for odd n, X = 2^{(n−1)/2} gives B = 1: X − 1, B = 2: X − 2,
B = 3: (3/2)X − 3, B = 5: (5/4)X − 5, and (3/2)X − 3 ≥ X − 1 iff X ≥ 4.

### Corollary 3 (CLM-C20-03) — the C04 census is complete

The six further rules of the two classes are images of these two under
reversal and letter exchange, which preserve termination and derivation
lengths. Hence all 868 one-rule systems over {a, b} with |l| ≤ 3, |r| ≤ 5 are
classified: 480 terminate and 388 do not (EXP-C04-02 left 8 undecided).

*Relation to the literature (Historian).* Both rules are *right barren* in
McNaughton's sense (A. Geser, "Termination of string rewriting rules that have
one pair of overlaps", ICASE Report 2002-33, Def. 3.1): for aab → ababa,
OVL(r, l) = {a} with r_α = abab and OVL(l, r) = {ab} with l_β = a, and a is not
a suffix of any (abab)^k; for aab → babaa, OVL(r, l) = {a, aa} with r_α ∈ {baba,
bab}, OVL(l, r) = {b} with l_β = aa, and aa is not a suffix of any concatenation
of baba and bab. Every left (by symmetry, right) barren one-rule system
terminates (McNaughton for non-overlapping ones; Geser's habilitation in
general). So termination is a **rediscovery**; the proof above is independent
and, unlike the barren criterion, yields the exact derivational complexity.
Barren rules can have exponential derivation lengths (already ab → bba,
C04 Theorem 6, which also has one pair of overlaps); the linear bound in
Geser's report is proved for its non-barren case only (remark after Lemma 6.8
of the report). A reader should be warned that the report's *introduction*
lists as its third contribution that "terminating one-rule SRSs with one
overlap pair are shown to have linear derivation lengths": aab → ababa has
exactly one pair of overlaps and D(n) = 2^{n−2} − 1, and ab → bba has
D(n) = 2^{n−1} − 1, so that sentence cannot be read literally; the body
proves the linear bound only for its rules of form (4.3). (Pointed out by the
Skeptic, reviews/skeptic_C07_C17_C20.md P9.)
