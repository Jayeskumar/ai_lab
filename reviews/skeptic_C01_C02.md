**Sources checked.**
- Gray–Steinberg 2026 Thm 8.1 (arXiv:2507.04819, HTML version via WebFetch): *"Let M = ⟨A ∣ u = v⟩ be an incompressible one-relator monoid with u, v ∈ A⁺, that is, there is no nonempty word r ∈ A⁺ such that u, v ∈ A*r ∩ rA*. Then M is of type bi-FP∞ and has Hochschild cohomological dimension at most 2."* Hochschild dimension means pd of ℤM over ℤ[M × M^op].
- Gray–Steinberg 2022 (arXiv:1910.09914 v1 PDF, read directly):
  - Thm 3.3(2)(i), p. 13: non-subspecial and incompressible ⇒ cd^{(l)}(M) ≤ 2.
  - Thm 6.6, p. 37: K contractible.
  - Thm 6.7: the exact sequence 0 → ℤM[z] → ℤM^{|A|} → ℤM → ℤ → 0.
  - Lemma 7.1.
  - Props 8.3, 8.5, pp. 44–46.

  The numbering in v1 agrees with the Historian's citations.

## Appendix A — proof of CLM-C02-04 (supplied by the skeptic; needs a second check)

**Theorem.** Let b_j ≥ 0, b_J > 0, Σ b_j = m ≥ 1. Let g = gcd{j : b_j > 0}, b′_i = b_{gi} and T′_i = Σ_{i′≥i} b′_{i′}. There is t* such that for every n ≥ t*·m the upward sweep from n tokens at level 0 reaches, on the levels gℕ, a window ≥ T′. Hence every maximal derivation from n is infinite.

*Proof.*

(i) *Reduction.* From a unary start only levels in gℕ are occupied. Renaming level gi to i yields derivations of (m; b′), and b′ has gcd 1 and Σb′ = m. So assume g = 1.

(ii) *Window dynamics.* As in Lemma 4, W_0 = t·b with t = ⌊n/m⌋, and W_{j+1} = F(W_j).

(iii) *Linear minorant.* Let A have (Ax)_i = x_{i+1} + (b_i/m)x_1, with x_{J+1} := 0. Since ⌊x_1/m⌋ ≥ x_1/m − 1, F(x) ≥ Ax − b. G(x) = Ax − b is monotone because A ≥ 0. By induction F^j(x) ≥ A^j x − Σ_{i<j} A^i b.

(iv) *Primitivity.* The digraph of A has arcs i+1 → i and 1 → i (for b_i > 0). It is strongly connected: J → … → 1 → J. Every cycle passes through 1, because all other arcs lower the index. The simple cycles are 1 → i → … → 1, of length i with b_i > 0, and their gcd is 1. So A is primitive and A^N > 0 for some N ≤ (J−1)² + 1 (Wielandt).

(v) *Conclusion.* A^N b > 0. Put C = Σ_{i<N} A^i b and t* = max_i ⌈(T_i + C_i)/(A^N b)_i⌉. For t ≥ t*, F^N(t b) ≥ t A^N b − C ≥ T. By Lemma 4 and Theorem 1 every derivation is infinite. ∎

*Complement (g = 1).* The window mass drops by x_1 mod m at each step. If the sweep never stops, the mass stabilises at M* > 0. From then on F = A exactly, so the windows are eventually periodic and A^p W = W. Since A is primitive with Perron vector T (AT = T), W = cT, and W_1 ≡ 0 (mod m) forces c ∈ ℤ_{≥1}. So non-termination ⟺ the window is eventually t′T, which explains the lab's observation that every glider is exactly T or its sparse version.
