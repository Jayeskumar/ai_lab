## Appendix A — proof of CLM-C02-04 (supplied by the skeptic; needs a second check)

**Theorem.** Let (m; b_1, …, b_J) satisfy b_j ≥ 0, b_J > 0 and Σ b_j = m ≥ 1. Let g = gcd{j : b_j > 0}, b′_i = b_{gi} and T′_i = Σ_{i′ ≥ i} b′_{i′}. There is t* such that, from every unary start n ≥ t*·m, the upward sweep reaches (on the levels of gℕ) a window dominating T′. Hence every maximal derivation from n is infinite.

*Proof.*

(i) *Reduction.* From n tokens at level 0, only levels in gℕ are ever occupied. Renaming level gi to i turns derivations of (m; b) into derivations of (m; b′), and b′ has gcd 1 and Σb′ = m. So assume g = 1.

(ii) *Window dynamics.* As in Lemma 4, the window after level 0 is W_0 = t·b with t = ⌊n/m⌋, and W_{j+1} = F(W_j).

(iii) *Linear minorant.* Let A be the J×J matrix with (Ax)_i = x_{i+1} + (b_i/m)x_1, where x_{J+1} := 0. Since ⌊x_1/m⌋ ≥ x_1/m − 1, we have F(x) ≥ Ax − b componentwise. G(x) = Ax − b is monotone because A ≥ 0. By induction, F^j(x) ≥ G^j(x) = A^j x − Σ_{i<j} A^i b.

(iv) *Primitivity.* The digraph of A has arcs i+1 → i and 1 → i (for b_i > 0). It is strongly connected: J → … → 1 → J. Every arc other than those leaving node 1 lowers the index, so every cycle passes through 1. The simple cycles are 1 → i → … → 1, of length i with b_i > 0. Their gcd is 1, so A is primitive and A^N > 0 for some N (Wielandt: N ≤ (J−1)² + 1).

(v) *Conclusion.* Since b ≥ 0 and b ≠ 0, A^N b > 0. Put C = Σ_{i<N} A^i b and t* = max_i ⌈(T_i + C_i)/(A^N b)_i⌉. For t ≥ t*, F^N(t b) ≥ t A^N b − C ≥ T. By Lemma 4 every later level fires, and by Theorem 1 every maximal derivation is infinite. ∎

*Complement (aperiodic case).* A firing at level k removes x_1 mod m from the window mass, so the mass is non-increasing. If the sweep never stops, the mass stabilises at M* > 0. From then on x_1 ≡ 0 (mod m) and F acts exactly as A, so the windows are eventually periodic, A^p W = W. A is primitive with Perron eigenvector T (AT = T), so W = cT, and W_1 ≡ 0 (mod m) forces c ∈ ℤ_{≥1}. So, for g = 1, non-termination is *equivalent* to the window eventually being t′T. This explains why every glider the lab observed was exactly T (or its sparse version).
